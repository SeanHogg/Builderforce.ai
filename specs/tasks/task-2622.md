3. **`ask_human` 500** — a prior call crashed this runtime. **Do not retry `ask_human`.**

**Goal**

On the next run, after GitHub quota resets, execute verify-and-package on a **shell-capable** executor bound to **SeanHogg/Builderforce.ai** as **builderforce/task-2555**. Produce a packaged VSIX coordinated with **#2562**. Do not dump conceptual Change A/B code.

## Scope

**In scope**

- Bind the run to **SeanHogg/Builderforce.ai** / **builderforce/task-2555**.
- Require a **shell-capable** executor.
- Run §3 verification in this order (or the repo’s documented equivalent): typecheck → test → dist.
- Package VSIX with `vsce package`.
- Coordinate artifact identity, version, and handoff with **#2562**.
- Record pass/fail, version actually packaged, and any pin/tree mismatch.

**Not in this run**

- Retrying `ask_human`.
- Emitting conceptual Change A/B patches or design dumps.
- Completing verify-and-package on a no-shell executor or while GitHub 403 persists.

## Functional requirements

1. **Executor gate** — Abort with a short status if the environment has no shell. Do not pretend to run pnpm/vsce.
2. **GitHub gate** — If list/read/search/write still 403, abort with status “quota not reset”; do not loop or hammer the API.
3. **No human escalation** — Never call `ask_human`.
4. **Repo binding** — All reads/writes and packaging target SeanHogg/Builderforce.ai, task `builderforce/task-2555`.
5. **Version reconcile** — Read package/extension version from the live tree. Treat `2026.9.72` as the pin; if the tree is `2026.9.79` (or other), follow #2560 and #2562 rather than silently rewriting the pin.
6. **§3 suites** — With shell: run typecheck, tests, and dist. Fail the task on first non-zero; do not package a failing tree.
7. **VSIX** — On green §3, run `vsce package`. Coordinate filename, version, and delivery with #2562. Do not produce a second competing VSIX story.
8. **Code discipline** — Implement or package only what the tree already specifies. No conceptual Change A/B code dumps, no drive-by refactors.
9. **Handoff** — Report: executor type, GitHub API health, commands run, suite results, VSIX path/version, #2562 coordination note, pin vs live version.
