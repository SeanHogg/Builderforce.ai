# Product Requirements Document (PRD)

## Problem & Goal

### Problem
The current implementation of the Builderforce.ai checkout process for project 11 lacks a source-control binding, preventing the Meeting Notes developer lane from writing code. This issue blocks the implementation of the Meeting Notes marketplace agent listing and the silent `runAgentTurn` wrap (#2539). Consecutive developer runs have failed to produce any code due to the absence of a repository binding.

### Goal
Bind the seanhogg/builderforce.ai checkout to project 11 to enable the Meeting Notes developer lane to write code. This will unblock the implementation of the Meeting Notes marketplace agent listing and the silent `runAgentTurn` wrap.

## Target Users / ICP Roles
- **Developer Lane Operators**: Responsible for managing and executing developer lanes within Builderforce.ai.
- **Product Owners**: Need to ensure that the Meeting Notes feature is correctly integrated and functional.
- **Architects**: Involved in designing and implementing the source-control binding solution.

## Scope

### In-Scope
1. **API Updates**:
   - Implement `api/src/application/meetings/meetingNotesListing.ts` to manage meeting notes agent interactions.
   - Update `api/src/application/meetings/meetingIntelligence.ts` to include a silent mode for `runAgentTurn`.
2. **Tenant Configuration**:
   - Add a `is_dogfood` boolean field to the tenants table with appropriate constraints.
   - Implement `isDogfoodTenant()` as a single predicate.
3. **Caption Persistence**:
   - Implement a try/catch hook for caption persistence that calls `maybeRunMeetingNotesTurn`.
4. **Testing**:
   - Develop tests for kind gate, silent side effects, sticky unhire, idempotent seed, failure isolation, and minutes parsing as per D-11.

### Out-of-Scope
1. **Deletion of `specs/tasks/task-2539.md`**:
   - The file cannot be deleted until the source-control binding is established.
2. **Related Bind Blockers**:
   - Issues #2600, #2554, #2556, #2557, #2558, #2618, #2622, and #2629 are not addressed in this PRD.
3. **Operator-Only GitHub Connect**:
   - The binding process is restricted to operator access and is not handled within this scope.

## Functional Requirements

1. **API Functionality**:
   - `api/src/application/meetings/meetingNotesListing.ts`:
     - Define `MEETING_NOTES_AGENT_ID` as `'meeting-notes'`.
     - Implement `ensurePublishedMeetingNotesListing`.
     - Implement `isMeetingNotesHired`.
     - Implement `ensureDogfoodMeetingNotesHire`.
     - Implement `maybeRunMeetingNotesTurn`.
   - `api/src/application/meetings/meetingIntelligence.ts`:
     - Implement `runAgentTurn(args, { silent?: boolean })` with silent mode that skips caption row, agent-say broadcast, and postChatMessage.
     - Replace-write `meetings.summary` when in silent mode.

2. **Tenant Configuration**:
   - Add a `is_dogfood` boolean field to the tenants table with a default value of `false` and a constraint that prevents it from being `true` if `is_demo` is `true`.
   - Implement a migration to handle the addition of the `is_dogfood` field.
   - Implement `isDogfoodTenant()` as a single predicate.

3. **Caption Persistence**:
   - Implement a try/catch hook that calls `maybeRunMeetingNotesTurn` to handle caption persistence without causing a 502 error in the room.

4. **Testing**:
   - Develop tests for:
     - Kind gate functionality.
     - Silent mode side effects.
     - Sticky unhire behavior.
     - Idempotent seed behavior.
     - Failure isolation.
     - Minutes parsing.

## Acceptance Criteria

1. **API Functionality**:
   - `api/src/application/meetings/meetingNotesListing.ts` is correctly implemented and passes all related tests.
   - `api/src/application/meetings/meetingIntelligence.ts` supports silent mode and correctly replaces the `meetings.summary` without triggering unwanted side effects.

2. **Tenant Configuration**:
   - The `is_dogfood` field is added to the tenants table with the correct constraints and default value.
   - The migration is successfully executed without issues.
   - `isDogfoodTenant()` behaves as expected, accurately reflecting the tenant's dogfood status.

3. **Caption Persistence**:
   - The try/catch hook for caption persistence is implemented and prevents 502 errors in the room.
   - `maybeRunMeetingNotesTurn` is called correctly within the hook.

4. **Testing**:
   - All tests are written and pass, ensuring the functionality of the new features and changes.

## Out of Scope

- Deletion of `specs/tasks/task-2539.md` until the source-control binding is established.
- Addressing related bind blockers (#2600, #2554, #2556, #2557, #2558, #2618, #2622, #2629).
- Operator-only GitHub connect process.
