# PRD: R3 package version bumps and brain-embedded dist rebuild

## Problem & Goal

Internal packages are out of date relative to the R3 cut. `api`, `brain-embedded`, `agent-loop`, and `agent-tools` must be bumped one patch each so downstream consumers and the already-shipped VSIX (`2026.9.72`) resolve a consistent set. After the `brain-embedded` bump, its distributable must be rebuilt so published artifacts match the new version.

**Goal:** Land R3 version alignment (`api` 2026.9.37, `brain-embedded` 2026.9.31, `agent-loop` 2026.9.17, `agent-tools` 2026.9.5), rebuild `brain-embedded` dist, and leave VSIX at 2026.9.72.

## Target users / ICP roles

- Release / packaging owners executing the R3 cut
- Downstream agents consuming this PRD for the same task
- Extension and runtime consumers of the bumped packages (no user-facing behavior change expected)

## Scope

- Patch-bump package versions only:
  - `api`: `2026.9.36` → `2026.9.37`
  - `brain-embedded`: `2026.9.30` → `2026.9.31`
  - `agent-loop`: `2026.9.16` → `2026.9.17`
  - `agent-tools`: `2026.9.4` → `2026.9.5`
- Update all in-repo version references, lockfiles, and dependency pins for those packages so they resolve the new versions.
- Rebuild `brain-embedded` dist so output matches `2026.9.31`.
- Leave VSIX version at `2026.9.72` (already current).

## Functional requirements

1. Set `api` version to `2026.9.37` everywhere that package version is declared or pinned.
2. Set `brain-embedded` version to `2026.9.31` everywhere that package version is declared or pinned.
3. Set `agent-loop` version to `2026.9.17` everywhere that package version is declared or pinned.
4. Set `agent-tools` version to `2026.9.5` everywhere that package version is declared or pinned.
5. Do not change the VSIX version; it remains `2026.9.72`.
6. Rebuild `brain-embedded` dist after the version bump so dist artifacts, manifests, and embedded version strings match `2026.9.31`.
7. Keep the change limited to version metadata, pins, and the `brain-embedded` rebuild; no feature or API surface changes.

## Acceptance criteria

- `api` reports `2026.9.37` (no remaining `2026.9.36` pins for this package).
- `brain-embedded` reports `2026.9.31` (no remaining `2026.9.30` pins for this package).
- `agent-loop` reports `2026.9.17` (no remaining `2026.9.16` pins for this package).
- `agent-tools` reports `2026.9.5` (no remaining `2026.9.4` pins for this package).
- VSIX version is unchanged at `2026.9.72`.
- `brain-embedded` dist is freshly built and consistent with `2026.9.31`.
- Lockfiles / workspace dependency graphs resolve the new versions without leftover old pins for the four packages.
- No unrelated source, API, or product behavior changes.

## Out of scope

- Bumping or rebuilding the VSIX (already `2026.9.72`)
- Feature work, API changes, or refactors
- Bumping any package other than `api`, `brain-embedded`, `agent-loop`, and `agent-tools`
- Publishing, marketplace release, or changelog/release-notes authorship beyond what the version files themselves require
- Major/minor version changes; this is patch bumps only
