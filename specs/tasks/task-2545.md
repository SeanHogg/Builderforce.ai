# PRD 26 — Advisor Platform as Marketplace Composition

WIP shared by every downstream agent. Spec path: `Builderforce.ai/specs/builderforce/26-prd-advisor-platform.md`. SCORE.org is a **capability checklist only** — compose equivalent founder support on existing Marketplace families. Do not clone SCORE.

## Problem & Goal

Founders need SCORE-like support — 1:1 mentoring, workshops, Academy courses, and stage toolkits — without a parallel advisor product, a fifth listing family, or SCORE/SBA/chapter machinery.

**Goal:** Compose that support on Talent `person` listings, `booking_services` / `booking_reservations`, `one_to_many` slots, stage-tagged `course` listings + LMS enrolment, and one toolkit `pack` per `BUSINESS_STAGES` value. Advisors are Talent people who offer bookable services, not a new kind.

**Success:** A founder with `seeking:mentorship` and `business_stage:mvp` can discover ranked Talent (including Free / price 0), book a non-overlapping 1:1, land in a restricted Brain thread plus calendar event, join a future workshop in the same family, enrol in a stage-tagged course, install the mvp pack, and keep seat agents on the roster — all without `/advisors`, a new listing family, or a volunteer table.

**Kill the epic** if any slice requires `/advisors`, a new `MARKETPLACE_LISTING_KINDS` value, or a volunteer table.

## Target users / ICP roles

| Role | Need |
|---|---|
| Founder | Discover mentors by stage and seeking intent; book 1:1s; join workshops; enrol in Academy; install the matching stage pack; optionally continue with the same advisor. |
| Advisor (Talent `person`) | Publish a Talent listing, attach bookable 1:1 and `one_to_many` services, run sessions into meetings/calendar/restricted threads. |
| Seat agent | Remain on the founder’s roster; must not be displaced by advisor composition. |
| Operator / marketplace admin | Curate Talent, services, courses, and packs using existing families and launch modes. |

No volunteer, SBA, or chapter roles.

## Scope

Composition only. Existing families and launch modes; no clone of SCORE.org IA.

| Slice | Composition | Hard constraints |
|---|---|---|
| **A0** (unblocker) | Bind Talent `person` listing ↔ `booking_services`. Book CTA on `/marketplace?family=talent`. | Do **not** add `advisor` to `MARKETPLACE_LISTING_KINDS`. Ranked discovery for `seeking:mentorship` + `business_stage:*`, including price 0. **A0 must be measurable before A3–A5 start.** |
| **A1** | Reservation → meeting + calendar event + restricted Brain thread. | Confidentiality default **restricted**. Thread is **not** in `aiContext` unless the founder invites. Overlap refused on `booking_reservations`. |

| **A5** | Continue-with-this-advisor engagement. | Prefer a **relation**, not a new table. |

Sequence: A0 → A1 / A2 in parallel after A0 is measurable → A3 / A4 / A5 only after A0.

## Functional requirements

### A0 — Talent ↔ booking_services (unblocker)

1. A Talent `person` listing may bind one or more `booking_services` (1:1 and later `one_to_many`) without a new listing kind.
2. `/marketplace?family=talent` shows a Book CTA on bindable listings; CTA starts the existing booking flow against the bound service.
3. Discovery ranks Talent for a founder with `seeking:mentorship` and a `business_stage` (including `mvp`). Ranking may use stage fit, seeking match, and price; **Free (price 0) must appear**.
4. No `/advisors` route, nav item, or listing-kind alias. Advisors are Talent people with bookable services.

### A1 — Reservation → meeting, calendar, restricted thread

5. Completing a 1:1 book writes `booking_reservations` and **refuses overlap** for the same advisor service window (and the founder’s conflicting reservation on that service).
6. On confirmed reservation, create a meeting, a calendar event for both parties, and a Brain thread whose confidentiality default is **restricted**.
7. Restricted advisor threads are omitted from `aiContext` unless the founder explicitly invites the thread (or its contents) into context.
8. Seat agents stay on the founder roster through booking and thread creation.

### A2 — Workshops as `one_to_many`

9. Workshops are `one_to_many` booking services on the same Talent family, not a webinar product.
10. Capacity is counted; join fails when the slot is full.
11. A founder who booked a 1:1 can join a **future** `one_to_many` slot from the same family.
12. No `/webinars` page and no in-person venue logistics.

### A3 — Stage-tagged courses + LMS

13. Course listings carry a `BUSINESS_STAGES` tag (`idea` \| `mvp` \| `early_revenue` \| `growth` \| `scale`).
14. Founder enrolment uses the existing LMS enrolment path.
15. Do not start A3 until A0 is measurable (Book CTA + ranked Talent including Free).

### A4 — Stage toolkits

16. Exactly one toolkit `pack` exists per `BUSINESS_STAGES` value.
17. A founder at `business_stage:mvp` can install the mvp pack through the existing pack-install path.
18. Do not start A4 until A0 is measurable.

### A5 — Continue-with-this-advisor

19. After a 1:1 (and optionally a workshop), the founder can continue with the same advisor via a **relation** on existing records (listing, reservation, or engagement), not a new table.
20. Continue-with does not introduce a listing family, volunteer table, or extra launch mode.
21. Do not start A5 until A0 is measurable.

### Cross-cutting

22. Do not add a fifth marketplace family or a sixth launch mode.
23. No SCORE branding, US-only gating, volunteer/SBA/chapter tables, or chapter affiliation.
24. Confidentiality and roster invariants hold for every slice: restricted by default; seat agents remain.

## Acceptance criteria

Kill the epic if any criterion can only be met with `/advisors`, a new listing family, or a volunteer table.

1. **Discovery.** A founder with `seeking:mentorship` and `business_stage:mvp` sees ranked advisors (Talent `person` listings) on `/marketplace?family=talent`, including Free (price 0), with a Book CTA. No `advisor` kind.
2. **1:1 book.** Booking writes `booking_reservations` and refuses overlap.
3. **Session artifacts.** After book, the founder lands in a restricted Brain thread plus a calendar event. Thread is not in `aiContext` unless the founder invites it.
4. **Workshop.** The same founder joins a future `one_to_many` slot from the same Talent family; capacity is counted. No `/webinars`.
5. **Academy + toolkit.** The founder enrols in a stage-tagged `course` and installs the mvp `pack`.
6. **Roster.** Seat agents remain on the roster after booking, thread creation, enrolment, and pack install.

A0 gate: criteria 1 is measurable before A3–A5 work starts.

## Out of scope

- Volunteer, SBA, or chapter tables; chapter affiliation; US-only eligibility
- SCORE branding, SCORE.org IA clone, or SCORE volunteer workflows
- Adding `advisor` to `MARKETPLACE_LISTING_KINDS` or any fifth marketplace family
- A sixth launch mode
- `/advisors` or `/webinars` pages
- In-person venue logistics
- A new continue-with-advisor table (use a relation)
- Putting restricted advisor threads in `aiContext` by default
- Starting A3–A5 before A0 is measurable
- Displacing seat agents from the founder roster
