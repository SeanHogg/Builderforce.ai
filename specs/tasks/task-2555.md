## Functional requirements

### Change A — Run visibility

1. **Composing tool-call stream.** While a run is composing, the UI surfaces a live composing label driven by the tool-call stream (not a stale idle or generic busy state).
2. **Idle watchdog.** An idle watchdog distinguishes true idle from in-flight composing so operators are not left on a silent/hung run with no composing signal.
3. **Triage context-pressure.** Triage/chat must not open with CONTEXT EXHAUSTION when context-pressure handling is in place; pressure is absorbed rather than dumped as a blocking banner.

### Change B — Ticket parent

4. **Rail names parent epic.** The ticket rail displays the parent epic name for the active ticket (not an orphaned or untitled parent line).

### Packaging with PRD 27

5. **Single VSIX.** Staffed-work + chat-diagnostics (PRD 27) and run-visibility + ticket-parent (this PRD) ship in one extension package.
6. **Version.** Packaged extension version is **2026.9.79** (#2614 decision (a); 2026.9.72 and 2026.9.71 are retired pins).
