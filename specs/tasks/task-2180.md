## Design

### AD-1 — Converter is a tsc Node CLI, not a Vite application

`/webdit/converter` (`@webdit/convert`) packs pre-exported diffusion-transformer ONNX graphs + safetensors weights into a WebDiT bundle. The product compile path does not go through Vite:

| Script | Command | Role |
| --- | --- | --- |
| `build` | `tsc -p tsconfig.json` | Production emit → `dist/` (`bin.webdit-convert` = `./dist/cli.js`) |
| `typecheck` | `tsc -p tsconfig.json --noEmit` | Types |
| `convert` | `tsx src/cli.ts` | Dev CLI (`tsx`, not Vite) |
| `test` | `vitest run` | Node test runner only |

There is **no** `vite.config.*` under `/webdit/converter` (glob `vite.config*` = 0 files). `webdit/converter/vitest.config.ts` is only:

```ts
import { defineConfig } from "vitest/config";
export default defineConfig({
  test: { include: ["test/**/*.test.ts"], environment: "node" },
});
```

No `server`, `optimizeDeps`, `preview`, plugins, CSS pipeline, or browser targets. Vite is not on the product runtime or bundle path. `tsconfig.json` targets ES2022, `module` ESNext, `types: ["node"]`, `outDir: dist`, `include: ["src/**/*"]`.
