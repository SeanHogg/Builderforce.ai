That GitHub PR is **already closed** (Dependabot, 2026-09-10: these dependencies are no longer a dependency) and its head branch is **deleted**. Cloudflare Pages failure on PR 820 is not a converter product signal.

The original “merge Vite 8 after validation” goal is therefore invalid. Treating this ticket as a live toolchain bump would reopen a deleted branch, invent a Vite 8 landing that the converter does not use as a direct dependency, or duplicate later Dependabot work.

**Goal:** Dispose ticket 2180 against already-closed GitHub PR 820. Record versions, inventory, security conclusion, and the close rationale in this PRD and in `specs/tasks/task-2180.md`. Do **not** merge or reopen PR 820. Do **not** retarget this ticket into a vitest-only bump. Remaining vitest / transitive-vite work is a follow-up, not this ticket.
