# PRD 29 — VSIX version pin 2026.9.72 (#2555 / #2561)

**Status:** WIP  
**Related:** #2555, #2561, parent #2560, #2562 (PRD 27), durable memory `vsix-install-pin-2561`  
**Pin policy:** packaged + installed version **2026.9.72** is mandatory. Do not retarget to **2026.9.79** without explicit operator confirmation.

## Problem & Goal

Live `clients/vscode/package.json` is recorded as **2026.9.79** (`vsix-install-pin-2561`). PRD 29 still requires the extension to be packaged and installed as **2026.9.72**. That pin drifted from **2026.9.71** when PRD 27 bumped the shared VSIX line; PRD 27 (#2562) is likewise held at **2026.9.72**.

#2561 must consume the already-packaged **2026.9.72** artifact. It must not bump `package.json`, must not rebuild or re-version the VSIX, and must not silently follow live tree version **2026.9.79**. The 72-vs-79 mismatch is a packaging gap owned by parent **#2560**, not a license for this PRD to retarget.

**Goal:** install and verify VSIX **2026.9.72** for the #2561 / PRD 29 path, keep the pin durable and coordinated with #2562, and leave version alignment to #2560 unless an operator explicitly confirms a retarget.

## Target users / ICP roles

- Downstream agents executing #2561 / PRD 29 install and verification
- Packaging owner for parent #2560 (72-vs-79 gap)
- PRD 27 / #2562 owners sharing the 2026.9.72 pin
- Operator who alone may authorize a pin change to 2026.9.79

## Scope

In scope for #2561 / this PRD:

- Treat **2026.9.72** as the required packaged and installed version for all PRD 29 work
- Locate and install the existing **2026.9.72** VSIX; do not produce a new package
- Record and honor durable memory `vsix-install-pin-2561` (live tree = 2026.9.79; required install = 2026.9.72)
- Coordinate pin language and artifact identity with #2562 so PRD 27 and PRD 29 do not diverge
- Fail closed if only a 2026.9.79 (or other non-72) VSIX is available
- Surface the 72-vs-79 delta to #2560; do not “fix” it by bumping this PRD

## Functional requirements

1. **Pin authority.** Required VSIX version for package + install is `2026.9.72`. Live `clients/vscode/package.json` at `2026.9.79` is observational only.
2. **No bump / no repackage.** #2561 must not change extension version, changelog, `package.json`, vsce/ovsx packaging inputs, or emit a new VSIX. Resolution of 72 vs 79 is #2560.
3. **Install from existing 72 artifact.** Install the already-built VSIX whose manifest version is exactly `2026.9.72`. Prefer the shared artifact also used by #2562.
4. **Identity checks.** After install, installed extension version must read `2026.9.72`. Do not accept 2026.9.71, 2026.9.79, or any other build as a substitute.
5. **Durable memory.** Keep `vsix-install-pin-2561` consistent: live clients/vscode = **2026.9.79**; this PRD’s install pin = **2026.9.72**. Do not overwrite the pin to 79.
6. **No silent retarget.** Changing the pin to 2026.9.79 (or any other version) requires explicit operator confirmation in-thread. Agent inference from the live tree is not confirmation.
7. **Coordination with #2562.** PRD 27 remains on 2026.9.72. Shared install steps, artifact paths, and pin text must stay aligned; neither PRD may advance the version independently.
8. **Escalation.** If 2026.9.72 cannot be installed because packaging only produced 79 (or mixed artifacts), stop and hand the gap to #2560. Do not locally retarget, cherry-pick, or rebuild.

- Using 2026.9.71 (pre–PRD 27 bump) as a stand-in for 2026.9.72
