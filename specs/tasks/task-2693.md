# PRD: Remove PRD-Forbidden `specs/tasks/task-2439.md` from `builderforce/task-2439`

## Problem & Goal

**Problem:** The branch `builderforce/task-2439` contains 8 commits of pure churn on `specs/tasks/task-2439.md`, a file explicitly forbidden by PRD #2439, Section P7 and Decision D-12 ("Do not create or merge specs/tasks/task-2439.md"). The file was deleted in execution 32132 and mistakenly re-added in execution 32185, leaving it live on the branch in violation of the governing PRD.

The branch was intended to carry a real product change (`clients/vscode/src/sessionsTree.ts`), but currently contains no product code at all — only the forbidden spec file.

A prior attempt to fix this via the standard developer execution (2026-09-16) failed because:
- The execution's workspace had no repository bound (read and write paths both returned "no repository bound to this task").
- The developer role in that run had no `delete_file` tool exposed.

**Goal:** Remove `specs/tasks/task-2439.md` from `builderforce/task-2439` so the branch is brought into compliance with PRD #2439 P7/D-12, leaving the branch with zero diff against `main` until legitimate product work is added.

## Target Users / ICP Roles

- **Operator** — a human or privileged automation role with a bound, writable git checkout, responsible for direct repository remediation outside the constrained developer-execution sandbox.
- **Run with bound checkout** — any future execution context where the repository binding issue (#2600) has been resolved and standard git/file tools are available.

*(Not applicable: this is an internal repo-hygiene task, not an end-user-facing feature.)*

## Scope

**In scope:**
- Removing the single forbidden file `specs/tasks/task-2439.md` from branch `builderforce/task-2439` via `git rm`.
- Verifying the resulting branch state matches `main` exactly (empty diff).
- Ensuring no PR is opened prematurely from this branch.

**Out of scope items are listed below.**

## Functional Requirements

1. **FR-1:** On branch `builderforce/task-2439`, run `git rm specs/tasks/task-2439.md` and commit the removal.
2. **FR-2:** After the commit, verify `git diff main...builderforce/task-2439` produces no output (empty diff).
3. **FR-3:** Do not open, reopen, or update any pull request from `builderforce/task-2439` as part of this task.
4. **FR-4:** This task requires a bound, writable checkout (blocked by #2600 if unavailable) and a role/tool with file-deletion capability (`git rm` or equivalent `delete_file` tool) — do not attempt via a workspace lacking repository binding.
5. **FR-5:** No other files on the branch should be modified, added, or removed as part of this action.

## Acceptance Criteria

- [ ] `specs/tasks/task-2439.md` no longer exists on `builderforce/task-2439` (confirmed via `git log` showing the removal commit and absence of the file in the branch tree).
- [ ] `git diff main...builderforce/task-2439` returns empty output.
- [ ] No pull request exists or has been opened from `builderforce/task-2439` as a result of this task.
- [ ] The branch remains otherwise unchanged (no unrelated commits, files, or history rewrites beyond the single removal commit).
- [ ] The fix was performed by an operator or execution with a confirmed bound repository checkout (not the constrained developer-execution sandbox that lacks repo binding/`delete_file`).

## Out of Scope

- Adding or restoring the real product change (`clients/vscode/src/sessionsTree.ts`) to this branch — tracked separately once the branch is clean.
- Opening a PR from `builderforce/task-2439`.
- Resolving #2600 (binding a readable/writable checkout for developer-execution runs) — this PRD depends on that being resolved or worked around, but does not implement the fix itself.
- Any changes to PRD #2439 itself, its P7 scope, or D-12 decision text.
- Rewriting branch history beyond the single `git rm` commit (e.g., squashing or rebasing prior churn commits).
- Root-causing why execution 32185 re-added the forbidden file — may warrant a separate follow-up task.
