# PRD: Delete `builderforce/task-2642` Branch Without Merging

## Problem & Goal

**Problem:** The branch `builderforce/task-2642` contains a net-empty diff against `main`. A prior agent pass created `specs/tasks/task-2642.md` on the branch, modified it three times, and then deleted it — all on the same branch. `main` never had a `specs/` directory to begin with. If this branch is opened as a PR, Project 11's policy (`allowAutoMerge:true`, `prMergePolicy:"on_green"`) would likely auto-merge it, permanently recording a merge commit that falsely implies issue #2642 shipped a repository artifact, when in fact it ships nothing.

**Goal:** Safely close out this branch without creating a misleading merge record, while preserving traceability to #2642's actual deliverable, which lives elsewhere.

## Target Users / ICP Roles

- **BuilderForce operator/agent** with git + GitHub write access (issue resolver executing this task).
- **Downstream agents** on #2642 and related tasks, who need an unambiguous signal that this branch is closed and not a source of shippable work.
- **Repo maintainers**, who need `main` and its history to accurately reflect real changes only.

## Scope

**In scope:**
- Verifying the branch `builderforce/task-2642` has an empty net diff vs `main`.
- Deleting the remote branch `builderforce/task-2642`.
- Ensuring no PR is opened or merged from this branch.

**Out of scope items are listed below.**

## Functional Requirements

1. **FR1 — Verification (optional but recommended):**
   - Run `git fetch origin`.
   - Run `git diff --stat origin/main...origin/builderforce/task-2642` and confirm the output is empty.
2. **FR2 — Deletion:**
   - Execute `git push origin --delete builderforce/task-2642` to remove the remote branch.
3. **FR3 — No PR creation:**
   - Do not open a pull request from `builderforce/task-2642` under any circumstances.
4. **FR4 — No file recreation:**
   - Do not recreate `specs/tasks/task-2642.md` on this or any other branch as part of this task.
5. **FR5 — Isolation from other branches:**
   - Do not modify, touch, or interact with `builderforce/task-2554` as part of this action.
6. **FR6 — Traceability preservation:**
   - Confirm/record that #2642's real deliverable (`git revert 0267ffd360e524dbd6ae8a93d1e71df8202d4dee` on `builderforce/task-2554`) remains tracked under #2642 and is unaffected by this branch deletion.
