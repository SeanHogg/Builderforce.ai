# PRD: Retire `builderforce/task-2581` Branch (Forbidden Spec Dump Cleanup)

## Problem & Goal

**Problem:** The git branch `builderforce/task-2581` contains 4 commits ahead of `main`, with no open pull request. Every commit in this branch touches exactly one file — `specs/tasks/task-2581.md` — which is a spec dump explicitly forbidden from shipping by three independent authorities: the ticket description, the PM product lock (exec 31846), and the PO ready verdict (exec 31952). The branch's entire net diff is therefore content that must never merge.

No agent can remediate this directly because project 11 has no bound repository (`githubRepoUrl`, `githubRepoOwner`, `githubRepoName`, and `sourceControlRepoUrl` are all null, confirmed via `projects.get(11)`). All repo-dependent tools (`list_files`, `read_file`, `git_status`, `run_command`, `delete_file`) fail with "no repository bound/checked out." This is tracked separately as root-cause issues **#2644** (urgent, blocked) and **#2600**.

**Goal:** Have a human operator with direct git access either delete the stale branch or strip the forbidden file from it, ensuring the forbidden spec dump can never be merged into `main` via this branch, while preserving the option to reuse the branch for legitimate future UI work if desired.

## Target Users / ICP Roles

- **Repo Operator / Release Engineer** — the human with direct git push access to the remote, who executes this task since no agent has repository access.
- **Engineering/Platform team** — consumers of a clean branch list and protected `main`, who benefit from removal of dead/forbidden branches.
- **Downstream agents on task #2581** — rely on the ticket PRD (system of record) rather than any repo artifact; unaffected by which remediation path the operator chooses, as long as the forbidden file does not ship.

## Scope

**In scope:**
- Human operator action on the remote git branch `builderforce/task-2581`.
- Two acceptable remediation paths (operator's choice):
  - **Case B (preferred/default):** Delete the branch outright since no PR exists and no repo artifact is needed.
  - **Case B-alt:** If the branch is to be retained for future UI work, remove `specs/tasks/task-2581.md` via `git rm`, commit, and push, leaving the branch clean of forbidden content.
- Confirmation that no PR is opened from this branch while it still contains the forbidden file.

**Out of scope for this action:** see "Out of Scope" section below.

## Functional Requirements

1. **FR-1:** Operator must verify current state of `builderforce/task-2581` before acting (4 commits ahead of `main`, single touched path `specs/tasks/task-2581.md`, no open PR).
2. **FR-2 (Path A — Delete):** If retention is not needed, operator runs:
   ```
   git push origin --delete builderforce/task-2581
   ```
3. **FR-3 (Path B — Strip forbidden file):** If the branch must be retained for future UI work, operator runs:
   ```
   git checkout builderforce/task-2581
   git rm specs/tasks/task-2581.md
   git commit -m "chore(#2581): drop PRD-forbidden spec dump; PRD is the system of record"
   git push origin builderforce/task-2581
   ```
4. **FR-4:** Under no circumstances should a pull request be opened from `builderforce/task-2581` while `specs/tasks/task-2581.md` is present in its history's working tree state — the forbidden file must not reach `main` in any form.
5. **FR-5:** No repo artifact needs to be created to preserve the #2581 Design (D-1–D-16, exec 32033); the ticket PRD remains the system of record and requires no synchronization with this branch.
6. **FR-6:** Once resolved, the outcome (deleted vs. stripped) should be noted back on the ticket/thread so downstream agents and #2644/#2600 tracking reflect current branch state.

## Acceptance Criteria

- [ ] `builderforce/task-2581` either no longer exists on `origin`, **or** exists with `specs/tasks/task-2581.md` fully removed from its HEAD.
- [ ] No pull request has been opened from `builderforce/task-2581` containing the forbidden file.
- [ ] `main` remains unaffected — no forbidden content was merged.
- [ ] If Path B was chosen, the branch's HEAD commit is the `chore(#2581): drop PRD-forbidden spec dump...` commit, and the file is confirmed absent via `git show HEAD --stat`.
- [ ] Ticket #2581 (and associated tracking on #2644/#2600 if relevant) is updated to reflect that the branch is resolved and no longer blocking.
- [ ] No agent action is required to complete this — resolution is confirmed as operator-executed.

## Out of Scope

- Fixing the root cause of project 11's missing repo binding (tracked separately in **#2644** and **#2600**).
- Restoring or granting agent-level git/repo access for project 11.
- Any modification to the #2581 Design content (D-1–D-16) — it is complete and already correctly stored in the ticket PRD.
- Creating a new PR or branch for future UI work related to #2581 (only branch retention/cleanup, not new feature scoping, is covered here).
- Auditing or cleaning up other stale branches beyond `builderforce/task-2581`.
