# Customer DPA operating exhibit

The public DPA at `/legal/dpa` is incorporated when BuilderForce is a processor/service provider. Contract operations must capture controller/processor roles, subject matter, duration, nature/purpose, people and data categories, documented instructions, confidentiality, security measures, subprocessors, assistance with rights/DPIAs/incidents, audit information, deletion/return, and applicable US state service-provider restrictions.

Security exhibit minimums: access control and MFA, tenant isolation, encryption in transit/at rest, secrets management, logging, vulnerability management, tested recovery, incident response, personnel confidentiality, vendor review, secure development, and deletion validation. Legal must execute the correct EU SCC module and UK Addendum when transfer analysis requires them.
