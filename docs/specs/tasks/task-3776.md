# PRD: M7 — bfi standalone release, ROADMAP, and blog

## Problem & Goal

Synapse’s product cut-over to in-process model serving is already public: Ollama is not required, the blog and release notes say so, `DONE.md` records the cut-over, and standalone install is documented as `cargo install --git https://github.com/SeanHogg/builderforce-inference bfi`. That product half landed 2026-10-12/14 (chat #135). M5 and M6 are done (#3766, #3767).

What is still open is the engineering release. There are no shipped GitHub Release binaries for the three CPU-sidecar targets, and signing secrets are not in place. `ROADMAP.md` still correctly shows Local LLM as partial. Marking that row done from this ticket alone would be false.

**Goal:** Finish M7’s engineering remainder without regressing the shipped product half: publish macOS aarch64, Windows x64, and Linux x64 GitHub Release binaries (signed if secrets exist, otherwise explicitly documented as unsigned-until-secrets), and leave the Local LLM roadmap row at partial until its real blockers land.

## Target users / ICP roles

- **Synapse operators** who need a standalone `bfi` sidecar and must not be told Ollama is required.
- **Installers** who use either the documented `cargo install --git` path or a GitHub Release binary for macOS aarch64, Windows x64, or Linux x64.
- **Release owner** who must add Apple Developer ID and Authenticode secrets before binaries can be signed.
- **Downstream agents** working in `seanhogg/builderforce.ai` (base `main`) who must not close child tickets or flip roadmap status early.

## Scope

Repo bound: `seanhogg/builderforce.ai`, base `main`. Inference install source: `https://github.com/SeanHogg/builderforce-inference`.

**Already shipped — do not redo or reopen:**

- Synapse release-notes paragraph: Synapse runs models itself; Ollama is not required.
- Blog post `synapse-runs-models-itself.md` on Builderforce.ai.
- `DONE.md` cut-over record.
- Documented standalone install: `cargo install --git https://github.com/SeanHogg/builderforce-inference bfi`.
- M5 (#3766) and M6 (#3767).

**Still in scope:**

- #3777 / #3782 / #4481: GitHub Releases binaries for macOS aarch64, Windows x64, and Linux x64, signed, or documented unsigned-until-secrets.
- Owner-supplied Apple Developer ID and Authenticode secrets. Agents must not invent or commit secrets.
- #3778: keep the `ROADMAP.md` Local LLM row at 🔄 Partial until #3762, #3764, and #3782 have landed. Do not move that row to DONE from this ticket alone.
- CPU-sidecar release only. GPU CI runners are not a blocker.

## Functional requirements

1. Publish a GitHub Release that includes CPU-sidecar binaries for macOS aarch64, Windows x64, and Linux x64.
2. If Apple Developer ID and Authenticode secrets are present, sign the macOS and Windows artifacts with them. If they are absent, ship the release as unsigned and document unsigned-until-secrets in the release notes. Do not claim signatures that were not produced.
3. The release owner adds the Apple Developer ID and Authenticode secrets. Track that as an owner action, not as something an agent can complete by editing the repo.
4. Keep the documented install command available and accurate: `cargo install --git https://github.com/SeanHogg/builderforce-inference bfi`.
5. Preserve the shipped Synapse copy: models run in Synapse; Ollama is not required. Do not reintroduce an Ollama requirement in release notes, blog, `DONE.md`, or install docs.
6. Leave #3777, #3782, #4481, and #3778 open until each child’s own acceptance criteria are met. Do not close them as a side effect of docs that already shipped.
7. On #3778, do not edit the Local LLM row from 🔄 Partial to DONE unless #3762, #3764, and #3782 have all landed. This ticket alone is not sufficient.
8. Treat a CPU-sidecar release as complete for this milestone even if no GPU CI runners exist.

## Acceptance criteria

- A GitHub Release exists with binaries for macOS aarch64, Windows x64, and Linux x64, or the missing asset is called out as not shipped and the child issue stays open.
- Each shipped binary is either signed with the owner-provided Apple Developer ID / Authenticode secrets, or the release explicitly documents unsigned-until-secrets. No unsigned binary is described as signed.
- Signing secrets are not committed to the repo. Absence of secrets does not block an unsigned, documented CPU-sidecar release.
- `cargo install --git https://github.com/SeanHogg/builderforce-inference bfi` remains the documented standalone install.
- Release notes, `synapse-runs-models-itself.md`, and `DONE.md` still state that Synapse runs models itself and that Ollama is not required.
- `ROADMAP.md` Local LLM remains 🔄 Partial unless #3762, #3764, and #3782 have landed. A PR that only flips that row to DONE is rejected.
- #3777, #3782, #4481, and #3778 stay open while their items above are unmet.
- No GPU CI runner is required to accept the CPU-sidecar release.

## Out of scope

- GPU CI runners and GPU-accelerated release artifacts.
- Re-writing or re-publishing the shipped blog, Synapse release-notes paragraph, or `DONE.md` cut-over, except to fix a regression of the Ollama-not-required statement.
- Closing M5 or M6, or relitigating #3766 / #3767.
- Moving the Local LLM roadmap row to DONE before #3762, #3764, and #3782 land.
- Creating, rotating, or storing Apple Developer ID or Authenticode secrets in git.
- Changing the product decision that Synapse runs models itself and does not require Ollama.
