# PRD: M7 — bfi standalone release, ROADMAP, and blog

## Problem & Goal

The product half of the Synapse cut-over to in-process model serving is **shipped** (2026-10-12/14, chat #135): Synapse runs models itself, Ollama is not required, the blog post `frontend/src/content/blog/synapse-runs-models-itself.md` (plus de/es/zh translations) is live, `DONE.md` records the cut-over, and the standalone install `cargo install --git https://github.com/SeanHogg/builderforce-inference bfi` is documented. M5 (#3766) and M6 (#3767) are done.

The **engineering remainder is not shipped**: there are no GitHub Release binaries for the three CPU-sidecar targets, and the Apple Developer ID / Authenticode secrets are not in place. The `ROADMAP.md` Local LLM row therefore stays 🔄 Partial.

**Goal:** finish M7's engineering remainder without regressing the shipped product half, and keep every status claim truthful.

## Target users / ICP roles

- **Synapse operators** — need a standalone `bfi` sidecar and must never be told Ollama is required.
- **Installers** — use `cargo install --git …` or a GitHub Release binary (macOS aarch64, Windows x64, Linux x64).
- **Release owner** — the only party who can supply Apple Developer ID and Authenticode secrets.
- **Downstream agents/reviewers** — must not close child tickets or flip roadmap status early.

### Functional requirements

- **R1 — Release assets.** One GitHub Release must carry CPU-sidecar binaries for macOS aarch64, Windows x64 and Linux x64. Any missing target is called out in the release notes as not shipped, and its child issue stays open.
- **R2 — Signing honesty.** If the owner-supplied Apple Developer ID / Authenticode secrets exist in CI, macOS and Windows artifacts are signed with them. If absent, the release ships unsigned and the release notes state "unsigned until signing secrets are added". An unsigned artifact must never be described as signed, notarized or Authenticode-signed.
- **R3 — Secrets are an owner action.** Secrets live only in the CI secret store. They are never committed, logged or echoed. Their absence must not fail the build; the workflow degrades to an unsigned, documented release (detect with a presence check on the secret env var, not by failing a signing step).
- **R4 — Install path.** `cargo install --git https://github.com/SeanHogg/builderforce-inference bfi` remains the documented standalone install and must stay accurate; Release binaries are an additional path, not a replacement.
- **R5 — No Ollama regression.** Release notes, the blog (all locales), `DONE.md` and install docs must not state or imply Ollama is required. Pre-existing mentions that Ollama-compatible HTTP APIs are *served by* bfi are accurate and allowed.
- **R6 — Roadmap guard.** The `ROADMAP.md` Local LLM row remains 🔄 Partial until #3762, #3764 and #3782 have all landed. A change that only flips that row is rejected.
- **R7 — Children stay open.** #3777, #3782, #4481 and #3778 are closed only when their own acceptance criteria are met — not as a side effect of docs that already shipped.
- **R8 — CPU only.** A CPU-sidecar release is complete for this milestone; no GPU CI runner is required, and no GPU parity is claimed.

## Acceptance criteria

1. A GitHub Release exists with the three binaries, or each missing asset is explicitly listed as not shipped and its child stays open.
2. Each shipped macOS/Windows binary is either signed with owner-provided credentials, or the release notes explicitly say unsigned-until-secrets. No unsigned binary is called signed.
3. No signing secret appears in the repository or in workflow logs.
4. The `cargo install --git … bfi` command is present and unchanged in the documented install section.
5. `synapse-runs-models-itself.md`, the release notes and `DONE.md` still state that Synapse runs models itself and Ollama is not required.
6. `ROADMAP.md` Local LLM row reads 🔄 Partial unless #3762, #3764 and #3782 are landed.
7. #3777, #3782, #4481, #3778 remain open while their items are unmet.
8. Acceptance does not depend on GPU CI.

## Out of scope

GPU runners/artifacts; rewriting the shipped blog, release-notes paragraph or `DONE.md` (except to repair an Ollama-required regression); closing M5/M6; flipping the roadmap row early; creating, rotating or storing signing secrets in git; reversing the "Synapse runs models itself" decision.

## Risks & open questions

- **Owner dependency (blocking for signed artifacts):** signing cannot start until the release owner supplies Apple Developer ID and Authenticode secrets (#3782). Mitigation: R2/R3 allow an honest unsigned release.
- **Where the release is cut:** the binaries are built from the sibling repo `SeanHogg/builderforce-inference`; this repo's `.github/workflows/` has no bfi release or signing job (searched for Authenticode: no matches). The release workflow belongs in the inference repo; this repo only carries docs/roadmap claims.
- **Unsigned-binary friction:** Gatekeeper/SmartScreen warnings on unsigned binaries should be documented next to the download links.
