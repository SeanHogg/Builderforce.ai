## Design

### R1 — closed-form 32K fit

- Shape: n_embd=5120 (bench-kernel default), n_layer=48 (`SYNTH_LAYERS`), GQA 40/8/128, qwen35 3+1 hybrid, giving 12 full-attention and 36 gated-delta layers.
- Budget: 36 GiB.
- Result: PTQ1_0 `needBytes` = 9,966,128,000; PQ2_0 = 11,226,128,000. Both `fits=true`.
- Only full-attention layers carry a KV cache that grows with context; delta layers hold fixed-size recurrent state. That is why 32K fits well inside budget.
- Tests: `crates/bfi-runtime/src/fit.rs::bonsai_27b_ctx32k_fits_36gib_or_documents_need`, `crates/bfi/src/fit.rs::bonsai_27b_fit_json_ctx_32768_budget_36gib`. `bfi-models` asserts 48-layer 3+1 yields 12/36.

### R2 — greedy harness

- `crates/bfi-runtime/tests/golden_greedy_27b.rs`: 10 prompts x 128 tokens via `generate_greedy_trace`.
- Gated on `BFI_GOLDEN_GGUF` / `BFI_GOLDEN_GGUF_27B`; skips unless `arch=qwen35`. `cargo test` without env passes (live test is ignored).
- Optional reference inputs: `BFI_LLAMA_IDS_27B`, `BFI_LLAMA_LOGITS_27B`.
