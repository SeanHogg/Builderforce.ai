# Native engine — remaining work

Status: WIP. Product cut-over shipped 2026-10-14 (chat #135). This epic and the ROADMAP Local LLM row stay open until M1, M3, and signed GitHub Release binaries all land. Repo: seanhogg/builderforce.ai, base `main`. Living doc: `builderforce-inference/docs/PRD-native-engine.md` (not present in this checkout; the inference crate lives in its own repo).

## Problem & Goal

Synapse no longer depends on a local Ollama process. The sidecar supervises `bfi serve`, the Ollama feature flag and `bf-local` `ollama.rs` path are gone, and the extension finds Synapse through the desktop config. That product cut-over is shipped. The native engine is not done.

Three gaps still block calling the epic complete:

1. GPU decode speed versus PrismML `llama-bench` tg128 has not been measured on Metal or NVIDIA, so the 70% tok/s bar is unverified.
2. Live Bonsai 27B greedy output has not been compared to the fork. The harness exists; 27B weights are not in CI.
3. GitHub Release binaries are not signed with the owner Apple Developer ID or Authenticode.

Goal: close those three items without reopening shipped cut-over work, without bumping CubeCL, and without marking ROADMAP Local LLM done early.

## Target users / ICP roles

- Synapse users running local models through the desktop sidecar (`bfi serve`), not a side Ollama install.
- VS Code extension users whose VSIX must discover the running Synapse from `~/.builderforce/desktop.json`.
- Installers of GitHub Release binaries who need Apple Developer ID and Authenticode signatures.
- Inference owners who must show GPU tok/s and Bonsai 27B greedy parity before the Local LLM row can leave Partial.

## Scope

In scope, still open:

- **M1** (#3762 / #4465): measure GPU tok/s on Metal and NVIDIA against PrismML `llama-bench` tg128. Bar ≥ 70%. CubeCL stays 0.10.0; cuda, rocm, metal, vulkan backends already compile.
- **M3** (#3764): run live Bonsai 27B greedy versus the fork on a machine that has the weights. No 27B weights in CI. Reuse the existing harness.
- **Signed releases** (#3782 / #4481 / #3777): GitHub Release binaries signed with the owner Apple Developer ID and Authenticode.
- **ROADMAP** (#3778): Local LLM stays 🔄 Partial until M1, M3, and signed releases have landed.

Already shipped; do not redo: M2 golden harness (#3763); M4 `mix_decode` + tools (#3765); M5 Synapse cut-over (#3766; `bf-local` `ollama.rs` and `SYNAPSE_USE_OLLAMA` deleted, sidecar supervises `bfi serve`, `import-ollama` kept in `crates/bfi/src/ollama.rs`); M6 VSIX discovery via `~/.builderforce/desktop.json` (#3767); M7 product slice (#3776: blog `synapse-runs-models-itself.md`, DONE.md cut-over entry, `cargo install` documented); CubeCL 0.10.0 backends compile.

## Functional requirements

Each requirement is numbered so the QA and validator slots can cite it.

### M1 — GPU decode throughput

- **FR-M1-1** Measurement runs on real Metal hardware and real NVIDIA hardware. A compile-only, CPU, or Vulkan-on-CPU result does not satisfy M1.
- **FR-M1-2** The report records, per GPU: device model, driver/OS version, model + quant, native-engine tg128 tok/s, PrismML `llama-bench` tg128 tok/s on the same device and same model/quant, the ratio, and a PASS/FAIL against 70%.
- **FR-M1-3** Run counts and spread are recorded (≥ 3 runs after a warm-up; report median and min/max) so a single lucky run cannot pass the bar.
- **FR-M1-4** CubeCL remains pinned at 0.10.0. The report states the resolved `cubecl` version from `Cargo.lock`. No backend bump is part of closing M1.
- **FR-M1-5** A GPU below 70% is reported as FAIL with the number; it is not rounded up or waived. The follow-up optimisation is a new scoped task, not a reason to relax the bar.

### M3 — Bonsai 27B greedy parity

- **FR-M3-1** M3 executes the existing greedy harness against live Bonsai 27B weights and the fork, outside CI.
- **FR-M3-2** Missing weights fail the run as **not-yet-run**, not as a pass. A skipped or weight-less CI job never counts.
- **FR-M3-3** The recorded result includes: weights file hash, fork commit, `bfi` commit, prompt set, token count compared, and first-divergence position (or "none").
- **FR-M3-4** M3 does not check 27B weights into the repo and does not require CI to download them.

### Signed releases

- **FR-REL-1** Release artifacts for the platforms covered by #3782, #4481, #3777 are GitHub Release binaries signed with the owner Apple Developer ID (macOS) and Authenticode (Windows). Unsigned uploads do not close the release item.
- **FR-REL-2** Signing uses the existing owner secrets. This epic does not invent a new signing identity.
- **FR-REL-3** Verification is recorded per artifact: macOS `codesign --verify --strict` plus notarization/`spctl` assessment; Windows `signtool verify /pa`. Evidence is the command output attached to the ticket.
- **FR-REL-4** Existing signing plumbing (`.github/workflows/release.yml`, `.github/workflows/native-apps.yml`, `agent-runtime/scripts/codesign-mac-app.sh`) is reused; the secrets prerequisite is tracked in #3782.

### Regression guards (shipped behaviour must still hold)

- **FR-KEEP-1** `import-ollama` stays available in `crates/bfi/src/ollama.rs`.
- **FR-KEEP-2** The sidecar continues to supervise `bfi serve`; `SYNAPSE_USE_OLLAMA` stays deleted.
- **FR-KEEP-3** VSIX discovers Synapse through `~/.builderforce/desktop.json` (`models.endpoint`) with `~/.builderforce/bfi.json` as the bare-`bfi serve` fallback, as implemented in `clients/vscode/src/gateway.ts`.
- **FR-KEEP-4** M7 product notes (blog, DONE.md entry, `cargo install` docs) stay in place.
- **FR-KEEP-5** ROADMAP Local LLM remains 🔄 Partial and this epic stays open until M1, M3, and signed releases are all done.
- **FR-KEEP-6** Cancelled 2026-10-14 duplicate role-wrappers (GPU / Synapse / VSIX / release) are not re-filed.

## Acceptance criteria

- **AC-1** M1 closed only after Metal and NVIDIA runs exist, each ≥ 70% of PrismML `llama-bench` tg128, with CubeCL still 0.10.0 (FR-M1-1…5).
- **AC-2** M3 closed only after a live Bonsai 27B greedy comparison versus the fork has been run outside CI and the harness result is recorded (FR-M3-1…4).
- **AC-3** #3782, #4481, #3777 closed only when the GitHub Release binaries are signed with the owner Apple Developer ID and Authenticode, with verification output attached (FR-REL-1…4).
- **AC-4** #3778 and this epic are marked done only after AC-1…AC-3. Partial is the correct ROADMAP state until then.
- **AC-5** FR-KEEP-1…6 still hold at close.
- **AC-6** No new issues recreate the cancelled role-wrappers.

- New signing identities, package formats, or release channels beyond the signed GitHub Release binaries already tracked.
