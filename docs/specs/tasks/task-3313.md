# Task 3313 — Auto SOC 2 evidence (PRD 08) for CC7/CC8

Parent: Epic 3062. Role: architect (lane `ready`).

## Finding

The gap as filed ("nothing writes agent-run/PR evidence automatically") is **stale**. Auto-capture is
implemented on `main`:

| Piece | Location |
| --- | --- |
| Writer (idempotent, best-effort) | `api/src/application/governance/automatedSocEvidence.ts` |
| Uniqueness guarantee | `api/migrations/1321_automated_evidence_and_incident_idempotency.sql` — partial unique index `uq_soc_evidence_auto_ref` on `soc_evidence(control_id, source_ref) WHERE source_ref LIKE 'auto:%'` |
| Tests | `api/src/application/governance/automatedSocEvidence.test.ts` |
| Reserved types | `RESERVED_EVIDENCE_TYPES` (`automated`, `override`) are refused by the manual evidence route in `soc2Controls.ts` |

## Design

`recordAutomatedEvidence(env, db, { tenantId, segmentId, kind, sourceId, url, note })` writes one
`soc_evidence` row per mapped control, with `evidence_type = 'automated'`,
`uploaded_by = 'system:devsecops'` and `source_ref = auto:<kind>:<id>`.

| Event (kind) | Controls | Call site |
| --- | --- | --- |
| Merged pull request (`merge`) | CC8.1 | `application/repos/recordPullRequestRow.ts` — every merge path converges here |
| Security scan finished (`scan`) | CC7.1, CC8.1 | `security/pullRequestSecurityStep.ts` (agent-run PRs, only when all scans completed untruncated) and `security/branchScanRun.ts` (manual scans) |
| Security review done (`review`) | CC8.1 | `security/pullRequestSecurityStep.ts` |
| Manager accepted-risk override (`override`) | CC8.1 | `security/prSecurityOverride.ts` — recorded as `override`, never as a clean scan |

Properties:

- **Idempotent**: `ON CONFLICT DO NOTHING` against the partial unique index; retried finalizes,
  overlapping sweeps and duplicate merge paths write the row once.
- **Best-effort**: failures go to `reportCaughtError` and return 0; evidence never blocks a merge.
- **Provenance**: `note` carries run id, PR url/number, commit sha, merge sha, task id; `source_ref`
  is the stable key.
- **Audited**: when `env` is supplied, each new row emits a `soc2-evidence` governance mutation
  under `SYSTEM_ACTOR`.
- **Segment-less events are skipped** (returns 0); evidence cannot be segment-less. Tenant-scoped
  overrides are filed under the tenant default segment.

## Residual gaps (not blocking Type I)

1. A `segmentId`-less PR row produces no evidence silently. Follow-up: surface a count of skipped
   events in the SOC 2 overview so the auditor can see coverage.
2. ROADMAP "Phase 7 — Planned" wording should be updated to reflect that auto-capture shipped.
3. Commit-level evidence for direct pushes (no PR) is not captured; branch protection requiring PRs
   is the compensating control.

## Manual fallback procedure (attach to CC7.1 / CC8.1)

Use only for a period or segment where auto-capture was not active, or for changes outside the PR path:

1. In the SOC 2 register, open the control (CC8.1 for change management, CC7.1 for vulnerability
   detection) for the relevant segment.
2. For each change in the audit window, add evidence with a non-reserved type (e.g. `document`,
   `screenshot`, `link`): title = PR/change title, url = PR link, note = reviewer, approval date,
   scan result, merge sha.
3. Do not use evidence type `automated` or `override`; the route rejects them.
4. Export via `soc2EvidenceExport` and hand the package to the auditor; automated rows are
   distinguishable by `uploaded_by = system:devsecops` and an `auto:` `source_ref`.

## Acceptance

Met: agent/PR merges create CC8.1 evidence; agent-run PR scans create CC7.1 and CC8.1 evidence; a
written manual procedure is recorded above for any period not covered.
