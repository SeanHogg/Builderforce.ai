## Problem & Goal

API drawer rows show an orange Undocumented diagnosis with no action beside it. Users marked those labels and asked for a Fix icon next to the diagnosis so they can start a contract fix without hunting for another control.

Goal: every undocumented endpoint row shows a square Fix icon immediately after the diagnosis. Activating it composes a prompt that names the method, path, and file and asks to add the missing OpenAPI contract and a test. Documented rows stay unchanged. The diagnosis word stays visible.

## Target users / ICP roles

Developers reviewing the BuilderForce knowledge-graph API surface in the visualization webview, who need to turn an undocumented or untested endpoint into a concrete compose action without leaving the drawer.

## Scope

- `surface/drawers/ApiEndpointRow.tsx`: Fix icon beside the Undocumented `StateLabel` when the endpoint is not documented.
- `surface/drawers/ApiEndpointCard.tsx` (and `ApiEndpointDetail` only if that is where Not tested and the contract `StateLabel` render): same Fix icon beside problem diagnoses — undocumented contract and not-tested.
- `surface/drawers/ApiPanel.tsx`: `onFix` calls existing `onCompose` with a templated prompt.
- `labels/surface.api.ts`: type union and English table keys for the icon label, accessible name, and compose prompt.
- `surface/drawers/ApiSandbox.test.tsx` (or the nearest API panel test): render coverage for the button, its absence on documented rows, and the compose call.

## Functional requirements

- When an endpoint is not documented, render a square icon button immediately after the `StateLabel` on the same row. Do not add a new text button.
- Icon is a 16×16 wrench SVG, `aria-hidden`, `currentColor` stroke, matching the icon button style in `surface/CameraBar.tsx` (square, border, panel background). Do not edit `CameraBar.tsx`.
- `aria-label` and `title` come from a new label key via the existing `fillTemplate` helper, using the request line the same way as `selectEndpoint`. No hardcoded English in the component.
- Button attributes: `data-action="fix"` and `data-testid="kg-api-fix"`.
- Clicking Fix must not also toggle row select.
- Documented rows get no Fix icon. The Undocumented word remains visible; the icon sits beside it.
- Label keys on `labels/surface.api.ts` (type union and English table):
  - `fix`: `Fix`
  - `fixAria`: `Fix {route}`
  - `contractFixText`: `Document {route} in {file}: add it to the OpenAPI contract and a test that calls the handler.`
- `ApiPanel` passes `onFix` that calls existing `onCompose` with `contractFixText` filled for method, path, and file.
- If `onCompose` is absent, render the icon disabled (`aria-disabled` / `disabled`). Use existing unavailable wording if one fits; otherwise `title` is `fixAria`. Do not hide the diagnosis.
- On the selected-endpoint card, add the same Fix icon beside each problem diagnosis: undocumented contract, and not-tested. One icon per problem, same `onFix`. Do not add Fix next to healthy KPIs (tested, documented, zero-is-fine counts).
- Extend the API panel render test: an undocumented row exposes a button named with the Fix accessible name; a documented row does not; clicking Fix calls `onCompose` with the route.

## Acceptance criteria

- Every Undocumented row in the API list has a Fix icon button beside the orange label.
- The button’s accessible name is the localized Fix label (`Fix {route}`), not a hardcoded string.
- Activating Fix calls `onCompose` with a prompt that includes method, path, and file and asks to add the OpenAPI contract and a test that calls the handler.
- The click does not toggle row select.
- Documented rows have no Fix icon and are otherwise unchanged.
- The diagnosis word remains visible.
- Selected-endpoint problem diagnoses (undocumented contract, not-tested) each have one matching Fix icon; healthy KPIs do not.
- When `onCompose` is absent, the icon is disabled and the diagnosis still shows.
- The render test covers the accessible name, absence on documented rows, and the `onCompose` call.

## Out of scope

- Restyling `AgentRunList`’s text Fix button.
- Removing or rewriting the Undocumented label.
- Editing `CameraBar`, `Segmented`, or stage tilt.
- Blocking on the design artifact URL.
- Hardcoded English in components; labels live in `surface.api.ts`.
- Fix icons on healthy KPIs (tested, documented, zero-is-fine counts).
