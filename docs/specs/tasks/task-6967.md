# PRD: Finish simulate-mode toggle in KnowledgeGraphView

## Problem & Goal

`KnowledgeGraphView.tsx` already renders a Simulate toggle and `SimulatePanel`, but the view does not typecheck. The toggle and panel read `simulateMode` / `setSimulateMode`, and the button is styled with an undeclared `pill` binding. Simulate-mode state was never declared, and `pill` is not imported.

Goal: make the existing simulate-mode toggle compile and behave as a local on/off control, styled with the shared pill helper, without changing product behavior beyond wiring that missing state and style.

## Target users / ICP roles

- Downstream implementers on `packages/knowledge-graph-view` who must land a type-clean simulate toggle.
- Operators of the knowledge-graph surface who use Simulate to preview graph behavior from the existing toggle and `SimulatePanel`.

## Scope

Repo: `seanhogg/builderforce.ai`, base `main`. Work only in `packages/knowledge-graph-view`.

In `KnowledgeGraphView.tsx`:

- Declare simulate mode next to the other `useState` calls: `const [simulateMode, setSimulateMode] = useState(false)`.
- Style the Simulate button with `pillStyle(simulateMode)` imported from `./surface/ui` (`Pill.tsx`). Do not reference an unimported `pill` binding.
- Keep the existing Simulate toggle and `SimulatePanel` wired to `simulateMode` / `setSimulateMode`.

Do not commit.

## Functional requirements

1. `simulateMode` starts `false` and is component-local React state.
2. The Simulate control calls `setSimulateMode` so the user can turn simulate mode on and off.
3. `SimulatePanel` continues to receive the current `simulateMode` (and setter only if it already does).
4. The toggle button’s style comes from `pillStyle(simulateMode)` via `./surface/ui`, so the active and inactive states are visually distinct using the shared pill style.
5. No new simulate-mode product behavior, API, or persistence is introduced.
6. Changes stay uncommitted.

## Acceptance criteria

- `KnowledgeGraphView.tsx` has `const [simulateMode, setSimulateMode] = useState(false)` beside the other `useState` calls.
- The Simulate button uses `pillStyle(simulateMode)` from `./surface/ui`; `pill` is not referenced unless it is a real, imported export (it is not the required style API).
- From `packages/knowledge-graph-view`, `pnpm exec vitest run src/surface/simulate.test.ts --pool=threads` passes.
- From `packages/knowledge-graph-view`, `pnpm --package=typescript dlx tsc --noEmit -p .` passes.
- Working tree is not committed.

## Out of scope

- Git commit, push, or PR.
- Redesign of `SimulatePanel`, pill visuals, or knowledge-graph layout.
- New simulate features, persistence, routing, or backend changes.
- Edits outside `packages/knowledge-graph-view` except what those two verify commands require.
- Rewriting or weakening `src/surface/simulate.test.ts` to hide a type error.
