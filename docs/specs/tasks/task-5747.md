## Design

### Position
The library layer is built; the epic is about **composition and landing**, not new libraries. Per `make.md` (verified against code 2026-11-18) G01, G03, G06–G19 and G21–G26 are built: durable store (`clients/vscode/src/durableLocalFirstStore.ts`), sync routes (`api/src/presentation/routes/syncRoutes.ts` at `/api/sync/v1`), named importers (`api/src/application/sync/importers/*`), `installSyncCoordinator.ts`, `installRunRecovery.ts`.

Still open: **G02** (one enforcement point), **G04** (chats across devices), **G05** (local projects/tickets), **G20** (fact provenance), **G27** (packaged network-denial acceptance), the shared offline memory scope, and the residual API chatter (delivery step 6).

### Architectural decisions

1. **One composition root.** `clients/vscode/src/extension.ts` is the single place that wires `install*` modules (policy, local domain tools, run change sets, run recovery, sync coordinator, dead-letter command). Library modules must not self-register; every library without a caller in `extension.ts` is considered not shipped.
2. **One enforcement point (G02).** Network-denial is decided in one gate (platform policy → `bindPlatformPolicy` host fetch / outbox `sendPermission` / model-routing gateway gate). New call sites must go through it; none may carry their own offline check.
3. **Local store is the system of record; the outbox is the only egress.** A domain write and its enqueue are one atomic local transaction (G14); revoke stops the outbox (G12); each queue is explicitly classified (G13, `g13QueueClassification.test.ts`). Server apply is idempotent by batch id and client-entity key, rejects bad `occurredAt`, and uses `baseVersion` for stale-write detection (G15–G18, G25; migration 1247).
4. **Fail closed on corrupt state.** A corrupt policy snapshot fails closed (shipped behaviour). The untracked test demanding recover-to-empty (#5938) is wrong and must be changed, not the code.
5. **Completion honesty.** The epic stays `codeDelivered:false` until the packaged acceptance suite (G27, #5861) has run with the network denied. G27 depends on G01, G02, G12, G15, G22, G26; no "offline-first shipped" claim before it passes.

### Landing rule (process fix for the recurring blocker)
Slices were stalled because they touched a file another agent had dirty. Rule:
- **One owner of the `extension.ts` composition diff.** Land the in-flight `extension.ts` edits together with their imported modules (`sendPermissionActivation.ts` etc.) as one commit, or discard them; an import must never land without its module.
- Slices that need `extension.ts` (#5936 dead-letter command, #5939 local read path) rebase onto that commit rather than carrying their own copy of those lines.
- Untracked-but-imported modules are a build break: before any commit, every relative import of a committed file must resolve to a tracked file.
