# UX — Execution Experience

**Priority: P1.** Visualize and control environments. The experience is organized around environments and workforces; the 3D Room visualizes real execution state rather than being a standalone meeting space.

Part of the [strategic roadmap](../../ROADMAP.md). Entry fields are defined in [00-STRATEGY.md](./00-STRATEGY.md#entry-format).


Users can inspect an agent, see its objective, tools, cost and current task, change its model, pause it or intervene. Authenticated UI meets PRD 21.
