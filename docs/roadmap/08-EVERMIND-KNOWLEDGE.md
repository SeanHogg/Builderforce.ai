# MEM — Evermind and Knowledge

**Priority: P1.** Improve agent intelligence and efficiency. Evermind is the persistent intelligence layer; each execution should be faster, cheaper and more accurate than the last.

Part of the [strategic roadmap](../../ROADMAP.md). Entry fields are defined in [00-STRATEGY.md](./00-STRATEGY.md#entry-format).


The knowledge graph supports execution decisions and is not a separate product. Prioritize retrieval quality, runtime integration and measurable reductions in context consumption over visualization modes.
