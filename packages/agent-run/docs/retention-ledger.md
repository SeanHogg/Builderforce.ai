# PRD 35 §7 — Retention ledger (nothing is lost)

Full copy of the §7 retention ledger from `docs/specs/35-prd-one-agent-one-kernel.md` (whose rows summarize the
design reference `docs/design/one-agent-one-kernel.html` "Every capability, and where it lives at the end"), brought up
to date at WS7 (2026-10-31): **Lives in now** names where the behaviour is, and **Proven by** names test files that exist.

- **Proven by** names the test files that exercise the capability at its end-state home. A test file marked *unchanged*
  is the source's own, run with only an import path retargeted. A test marked *pins* was written against the one home
  because the old home is already deleted: it fixes today's behaviour and is **not** a parity proof (§5.1 step 2 could not
  be followed for it).
- **Held** means the old copy is still alive and the row is not finished: the old home, and what holds it.
- Rows whose old home is `api/src` governance (§6.9) are **untouched**: the governance layer keeps its single owner.
- Paths are repo-relative. Every test path below was checked to exist on `main` at WS7 time. "Exists" is not "passes":
  the verifier runs them.
- The earlier **needs characterization test** markers are closed in this revision, each by a named test, or retired where
  the old home is gone (the Claude SDK loop), or marked **Held** with what holds it.
