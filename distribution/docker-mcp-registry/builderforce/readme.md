# Builderforce

Run your Builderforce workspace from any MCP client: create and move tickets, drive boards and swimlanes, read and update portfolios, initiatives and OKRs, dispatch cloud coding agents, and query executions — plus every connector and external MCP server your tenant has connected.

Docs: https://builderforce.ai/docs/gateway/mcp

## Authentication

Send a Builderforce tenant API key as `Authorization: Bearer bfk_…`.
Create one in Settings → API keys. The key's tenant is the scope of every tool call.
