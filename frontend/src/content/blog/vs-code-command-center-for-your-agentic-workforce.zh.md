开发者的日常就在编辑器里。所以 Builderforce.ai 不要求你离开它，而是把整个平台*搬进* VS Code。这个扩展早已不只是一个聊天面板——它是一个**指挥中心**，让你调度由人类与 AI 智能体混合组成的团队，协作、会议、实时状态和模型训练全都集中在侧边栏里。

> BuilderForce VS Code 扩展把整个平台装进你的编辑器：多方团队聊天、实时会话状态、原生视频会议、Evermind 训练控制台、项目与任务树，以及人在回路的审批——让你无需离开 VS Code，就能管理一整支智能体劳动力。

下面逐一介绍侧边栏的每个界面能为你做什么。

| 侧边栏界面 | 功能 |
| --- | --- |
| **会话** | 多方团队聊天——人类 + `@agents`、定向消息、头像 |
| **项目与任务** | 你的看板和分配给你的工作，每一行都叠加实时状态 |
| **会议** | 即将开始和正在进行的通话——在浏览器中加入，或在 webview 中原生加入 |

| **收件箱** | 人在回路的审批与决策 |

## 谁在等你——一眼便知

同时运行好几个智能体时，最难回答的问题是："现在哪个需要我？"一个服务端信号就能在所有界面上给出答案。在 VS Code 中，**会话**树和**项目与任务**树都会在每一行上叠加一个实时状态图标：

- **执行中**——蓝色旋转图标：智能体正在工作（即使你切换到别的聊天，它也会继续工作）。
- **等你回答**——带 `❓` 的琥珀色标记：运行因一个问题而暂停，正在等你。
- **已完成**——绿色对勾。

![三行实时状态——蓝色旋转图标表示执行中，琥珀色问号表示等你回答，绿色对勾表示已完成——这是跟随会话出现在每个界面上的同一个信号](/blog/vscode-live-status.svg)

无论会话显示在哪里，状态都会随之出现，所以在多个并发运行之间切换时，一眼就能看清全局。

## 侧边栏里的多方团队聊天

会话面板是真正的团队聊天，而不是一个单人提示框。线程在整个项目内共享，你可以邀请人类和 AI 智能体加入同一个房间，并把每条消息发给特定的参与者——和同事对话，或 `@mention` 一个智能体，让它回复并在你的权限范围内操作看板。参与者以彩色头像直接显示在树中，谁在哪个房间一目了然。

## 原生加入会议

**会议**树列出你即将开始和正在进行的通话。**在浏览器中加入**会打开已认证的网页会议；**在此加入**则在 *VS Code webview 中原生*运行网状 WebRTC 视频通话。站会、规划会和回顾会都能进行，而你始终不必离开代码。

## 查看并训练 Evermind

每个项目都有自己的 **Evermind**——一个从团队工作中学习、会自我更新的模型。现在它成了侧边栏里的一等视图。打开 Evermind 控制台，就能看到它学到了什么（版本、已学习/排队数量、最近一次学习时间），引导它的训练（从已发布的模型初始化、连接或冻结学习、选择教师模型），通过粘贴一个范例**用对话记录教它**，还能随时清空学习队列。管理者拥有这些控制权；所有人都可以查看。同一个控制台也会在网页端呈现——一个组件，两个宿主。

## 驱动工作的各棵树

扩展还承载了平台的其余部分：

- **项目与任务**——你的看板和分配给你的工作，同样叠加实时状态。
- **收件箱**——需要你审批和决策的事项。
- **洞察**和**诊断**——运营全景和各类扫描。
- **运行与审阅**——把任务派发给智能体，审阅并验证它们的产出，在写代码的地方就批准人在回路的操作。

## 受治理，且归你掌控

受支持的 VS Code 执行路径会使用平台配置好的审批流程和可用的执行记录。模型的可用性与计费取决于当前的模型目录、凭据、套餐和运行时；网页端与扩展之间的功能对等情况按能力逐项列出。

## 为什么这很重要

上下文切换是管理智能体要付出的"税"。每次为了查看一次运行、回答一个问题、参加一场站会或调一次模型而离开编辑器，你都会丢掉思路。VS Code 指挥中心免掉了这笔税：整支劳动力——它的聊天、会议、状态和学习模型——都在离你的代码只有一个面板之遥的地方。

## 常见问题

**不用逐个打开，我能知道哪个智能体需要我吗？** 可以。会话树和项目与任务树会在每一行叠加实时状态——蓝色旋转图标表示执行中，琥珀色 `❓` 表示等你回答，绿色对勾表示已完成——全部来自同一个服务端信号。

**VS Code 里的聊天只是我和一个模型对话吗？** 不是。它是多方的：线程在整个项目内共享，你可以邀请人类和智能体，并把消息发给特定参与者——包括用 `@agent` 提及，让智能体在你的权限范围内回复并执行操作。

**我能在 VS Code 里加入视频会议吗？** 可以。会议树让你在浏览器中加入，或在 VS Code webview 中原生运行 WebRTC 通话。

**我能在编辑器里训练项目的模型吗？** 可以。Evermind 侧边栏视图让管理者查看模型学到了什么、引导训练、通过粘贴对话记录教它，以及清空学习队列——和网页端出现的是同一个控制台。

**在 VS Code 中执行的智能体操作会绕过治理吗？** 受支持的执行路径会使用其配置的平台策略。请针对你打算执行的操作核对能力矩阵，因为网页端到扩展的覆盖并非全部一致。
