“让智能体更谨慎一点”只是一个愿望，而**个性**才是一份规格说明。Builderforce.ai 让你为智能体赋予真实、可测量的性情——使用与评估人类相同的心理测量框架进行评估——然后把这种性情编译成智能体实际的提示与执行方式。结果是：“谨慎的评审者”和“快速的原型师”不只是名字不同，行为也不同，而且始终如一。

> 在 Builderforce.ai 中，心理测量角色（persona）是一个特质向量（每个维度 0–100），通过简短问卷或 HEXACO、Enneagram、MBTI 等框架上的滑块设定。该向量会被编译成具体的提示指令和执行参数——因此智能体的个性驱动的是真实、可重复的行为，而不是一个标签。

## 从测试到特质向量

你不需要手写行为。你做一份简短的**人格测试**——或者直接拖动滑块——平台就会记录一个**特质向量**：每个维度打分 0 到 100，50 为中性。你可以通过自己信任的框架来评估；它们都汇入同一个底层向量。

![六种评估框架——HEXACO、Enneagram、MBTI、调节焦点、冲突风格和 Schwartz 价值观——汇聚成一个特质向量，进而驱动一个角色或智能体](/blog/persona-frameworks.svg)

| 框架 | 它刻画的内容 |
| --- | --- |
| **HEXACO** | 广泛的人格维度（诚实-谦逊、情绪性、外向性等） |
| **Enneagram** | 核心动机——行为背后的*原因*（改革者、成就者、探究者……） |
| **MBTI** | 认知风格类型偏好 |
| **调节焦点** | 促进（追求收益）与预防（避免错误）取向 |

| **Schwartz 价值观 / 道德基础** | 它优先考虑什么，以及绝不拿来交换的是什么 |

## 从向量到行为

仅有特质向量是惰性的。Builderforce 会在运行时把它**编译**成两样具体的东西：

- **提示指令**——模型收到的直白指示。高谨慎度变成“在声称完成之前再检查一遍边界情况”；低果断度变成“陈述假设，并在执行不可逆操作前先询问”。
- **执行参数**——围绕模型的各种旋钮：温度、详略程度、重试耐心、寻求批准的积极程度，以及向人类升级求助的难易程度。

所以个性不是装饰。它改变的是*智能体被告知要做什么*，以及*运行时允许它如何行动*。

## 个性是设定点；边缘系统是动态

静态的个性只会是一幅漫画。Builderforce 为角色搭配了一个可训练的**边缘（limbic）层**——一个提供即时动态的情感模型。个性设定**设定点**（智能体从根本上是谁）；边缘层掌管**动态**（它在当下如何反应），并搭载在同一个自我更新的模型 [Evermind](/blog/evermind-self-updating-model) 上，该模型承载着你项目的其余学习成果。最终得到的是一个跨会话始终*保持角色*而不漂移的智能体。

## 角色存放在哪里

角色是可复用的。构建一次，然后：

- 把它挂到可跨项目复用的**角色（persona）**上，或直接挂到**智能体**上，由它带入每一次云端运行。
- 为不同岗位分配不同角色——QA 泳道上是一丝不苟的评审者，探索泳道上是大胆的原型师。

心理测量角色是 **Pro** 功能；平台会明确标示哪个套餐可解锁，并且绝不会悄悄降级。

## 为什么它重要

团队早就知道性情会塑造结果——你为一次微妙的迁移配备的人选，与为全新的探索性冲刺配备的人选不同。智能体团队也应该拥有同样的杠杆。通过真实框架评估个性，并把它编译成指令和运行时参数，Builderforce 把“更小心一点”从一句充满期望的提示，变成了智能体持久、可测量的特质。

## 常见问题

**如何设置智能体的个性？** 做一份简短的心理测量问卷，或在各特质维度上拖动滑块。无论哪种方式，你都会得到一个特质向量（每个维度 0–100），平台会把它保存在角色或智能体上。

**支持哪些人格框架？** 多种——包括 HEXACO、Enneagram、MBTI、调节焦点、双加工认知、决策风格、Thomas-Kilmann 冲突风格、Schwartz 价值观和道德基础。它们都汇入同一个底层特质向量。

**个性真的会改变行为，还是只是个标签？** 它会改变行为。特质向量会编译成提示指令（智能体被要求做什么）和执行参数（温度、详略、寻求批准、升级求助），因此不同的角色行为不同。

**智能体会在不同会话间保持角色吗？** 会。个性提供稳定的设定点，可训练的边缘层提供一致的动态，两者都搭载在项目的 Evermind 模型上——因此行为是可重复的，而不会在每次运行间漂移。

**免费套餐可用吗？** 心理测量角色是 Pro 功能。平台会在升级提示中显示所需套餐，并始终如一地执行付费功能门槛。
