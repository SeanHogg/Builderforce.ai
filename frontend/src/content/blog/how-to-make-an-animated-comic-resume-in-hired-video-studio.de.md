## Wann ein Comic einen Talking Head schlägt

Für die meisten Rollen ist ein 60-sekündiger Talking-Head-Video-Lebenslauf das wirkungsvollste Asset, das Sie erstellen können. Bei Design-, Illustrations-, Motion-, Marketing- und Brand-Rollen will eine Hiring Managerin oder ein Hiring Manager Ihre Ästhetik aber *sehen*, nicht nur hören, wie Sie sie beschreiben. Ein animierter Comic-Lebenslauf ist das Format, das Ihr Handwerk auf die Seite bringt.

Die Medienart Animation im Studio bietet Ihnen eine Leinwand mit Ebenen und eine Keyframe-Timeline. Sie bauen Panels, platzieren Ebenen (Hintergrund, Figur, Sprechblasen) und animieren Eigenschaften – Position, Skalierung, Deckkraft – über die Zeit. Das Ergebnis ist ein kurzes gerendertes Video, das Sie in Ihrem Profil veröffentlichen oder einer Bewerbung beifügen können.

## Schritt 1: Ein Animationsdokument beginnen

Öffnen Sie das [Studio](/creation-canvas), legen Sie ein neues Dokument an und wählen Sie die Art **Animation**. Der Editor lädt eine Leinwand plus eine Keyframe-Timeline. Legen Sie zuerst das Seitenverhältnis fest – quadratisch (1:1) wirkt gut im Feed, 16:9 läuft sauber als eingebettetes Video.

Denken Sie wie ein Comic in Panels: 4–8 Panels, jedes ein einzelner Schlag Ihrer Geschichte. Skizzieren Sie die Schläge vor dem Bauen – „Intro“, „das Projekt“, „das Ergebnis“, „die Bitte“ –, damit Sie nach einem Skript animieren, statt zu improvisieren.

## Schritt 2: Ebenen und Sprechblasen bauen

Jedes Panel ist ein Stapel von Ebenen. Fügen Sie einen Hintergrund, eine Figur oder Illustration und Textebenen für Bildunterschriften und Sprechblasen hinzu. Das Ebenenmodell des Studios ist dasselbe wie in der Video-Leinwand, alles, was Sie in eine Videoszene setzen können – Formen, Bilder, Text, Schriften –, funktioniert auch hier.

Halten Sie Texte kurz. Eine Comic-Sprechblase, für deren Lesen man länger als zwei Sekunden braucht, bricht das Tempo. Lassen Sie die Bilder die Geschichte tragen und verankern Sie mit Bildunterschriften die wichtigsten Fakten (Ihren Namen, die Kennzahl, die gewünschte Rolle).

## Schritt 3: Mit Keyframes animieren

Wählen Sie eine Ebene, bewegen Sie den Abspielkopf und setzen Sie Keyframes auf die Eigenschaften, die Sie animieren möchten. Lassen Sie eine Figur von außerhalb der Leinwand hereingleiten, blenden Sie eine Bildunterschrift ein, lassen Sie eine Sprechblase mit einer schnellen Vergrößerung aufploppen. Das Studio interpoliert zwischen Keyframes, daher genügen für eine saubere Bewegung meist zwei Keyframes pro Eigenschaft.

Setzen Sie auf wenige selbstbewusste Bewegungen statt auf ständige Bewegung. Die wirkungsvollsten Comic-Lebensläufe halten jedes Panel lange genug zum Lesen und wechseln dann mit einer bewussten Animation, statt alles gleichzeitig zu animieren.

## Schritt 4: Im Browser rendern und veröffentlichen

Der Export rendert die Animation clientseitig zu Video, mit derselben ffmpeg.wasm-Pipeline wie bei jeder anderen Medienart im Studio – ohne Upload, ohne Server-Warteschlange. Fügen Sie vorher eine Audiospur hinzu, wenn Sie Sprecherkommentar oder einen Musikteppich möchten; KI-Voiceover funktioniert hier genau wie beim Video.

Veröffentlichen Sie den gerenderten Clip in Ihrem Profil, hängen Sie ihn an eine kreative Bewerbung an oder posten Sie ihn als Creator. Für Design- und Motion-Rollen ist ein Comic-Lebenslauf oft das eine Asset, durch das man in einem Stapel PDFs in Erinnerung bleibt.

## Häufig gestellte Fragen

### Muss ich Illustrator sein, um einen Comic-Lebenslauf zu machen?

Nein. Sie können Panels aus Formen, Text und importierten Bildern bauen. Starke Illustration hilft speziell bei Illustrationsrollen, aber das Format funktioniert mit einfachen Ebenengrafiken – die Erzählstruktur zählt mehr als das Zeichnen.

### Was ist der Unterschied zwischen der Art Animation und einem Video?

Beide exportieren zu Video, aber die Art Animation baut auf einer Keyframe-Timeline und einer Leinwand mit Ebenen für synthetische Bewegung auf, während die Art Video auf aufgenommenen Szenen und einem Teleprompter basiert. Nutzen Sie Animation, wenn Sie Bewegung aus Ebenen erzeugen; nutzen Sie Video, wenn Sie sich selbst aufnehmen.

### Wo findet das Rendern statt?

In Ihrem Browser. Das Studio nutzt ffmpeg.wasm, um das fertige Video clientseitig zu rendern, sodass Ihre Assets nicht auf eine Render-Farm hochgeladen werden müssen und keine Infrastrukturkosten pro Render entstehen.
