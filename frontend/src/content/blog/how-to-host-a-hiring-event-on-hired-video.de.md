## Warum ein Event statt einer Stellenanzeige

Eine Stellenanzeige ist passiv – Sie warten auf Bewerbungen. Ein Event ist aktiv – Sie schaffen einen Moment, zu dem Menschen erscheinen. Karrieremessen, virtuelle Infoveranstaltungen, Hiring-Meetups und AMAs verwandeln Interesse schneller in eine Shortlist als eine statische Anzeige, denn schon die Teilnahme ist ein Signal für ernsthaftes Interesse.

Events stärken außerdem Ihre Arbeitgebermarke. Kandidatinnen und Kandidaten, die Ihre Infoveranstaltung besuchen, kommen bei jeder späteren Stelle wärmer an, weil sie Sie bereits kennengelernt haben. Bei Builderforce ist ein Event ein vollwertiges Objekt mit eigener öffentlicher Seite, eigenem RSVP-Ablauf und eigener Verwaltungsansicht.

## Schritt 1: Das Event anlegen

Öffnen Sie [Event erstellen](/meetings) und füllen Sie die Grundlagen aus: Titel, Beschreibung, Datum und Uhrzeit, Format (vor Ort oder virtuell) sowie Ort oder Meeting-Link. Schreiben Sie die Beschreibung aus Sicht der Kandidaten – was sie von der Teilnahme haben, wer kommen sollte und was sie erwartet.

Ein klarer, konkreter Titel schlägt einen cleveren. „Backend Engineering Hiring AMA – Dienstag 13 Uhr PT“ sagt jedem genau, ob sich das Erscheinen lohnt; „Seien Sie dabei bei einem spannenden Abend!“ tut das nicht.

## Schritt 2: Die öffentliche Seite teilen

Jedes Event erhält eine öffentliche Seite unter einer eigenen URL (`/events/<id-or-slug>`), die jeder ansehen und für die jeder per RSVP zusagen kann – zum Ansehen ist kein Konto nötig. Teilen Sie diesen Link in Stellenanzeigen, auf Ihrer Unternehmensseite, in der Ansprache und in sozialen Netzwerken. Die Seite ist die zentrale Anlaufstelle für das Event; alles verweist auf sie.

Da die Seite öffentlich und teilbar ist, dient sie zugleich als Marketing-Asset. Eine gut geschriebene Event-Seite taucht in der Suche auf und gibt Kandidaten einen sauberen, gebrandeten Ort für ihre Zusage.

## Schritt 3: RSVPs verwalten und den Tag durchführen

Sobald die ersten Zusagen eintreffen, verwalten Sie das Event in seiner [Verwaltungsansicht](/meetings) (`/events/<id>/manage`): Sehen Sie, wer kommt, senden Sie Updates und planen Sie für die Teilnehmerzahl. Am Veranstaltungstag führen Sie die Session von derselben Stelle aus – die Verwaltungsansicht ist Ihre operative Zentrale für das Event.

Fassen Sie nach dem Event schnell nach. Die Teilnehmenden, die erschienen sind, sind Ihr wärmster Top-of-Funnel; ein Follow-up noch am selben Tag, solange das Gespräch frisch ist, konvertiert deutlich besser als ein generischer Massenversand eine Woche später.

## Häufig gestellte Fragen

### Können Kandidaten ohne Builderforce-Konto per RSVP zusagen?

Jedes Event hat eine öffentliche Seite unter einer eigenen URL, die jeder ansehen kann; Kandidaten können das Event also ohne Registrierung finden und darüber lesen. Die öffentliche Seite ist die teilbare Heimat des Events, auf die Sie Ihre gesamte Bewerbung ausrichten.

### Wo verwalte ich ein Event, sobald es live ist?

In der Verwaltungsansicht des Events unter /events/<id>/manage. Dort sehen Sie die RSVPs, senden Updates und führen den Tag durch. Die öffentliche Seite unter /events/<id-or-slug> ist das, was Kandidaten sehen.

### Welche Art von Events funktioniert für das Recruiting am besten?

Alles, was einen Anlass zum Erscheinen schafft: virtuelle Infoveranstaltungen, Hiring-AMAs, Karrieremessen und Meetups. Sie verwandeln Interesse schneller in Bewerbungen als eine statische Stellenanzeige, weil die Teilnahme Absicht signalisiert – und sie machen Kandidaten für jede später ausgeschriebene Stelle empfänglicher.
