聊天让生成式 AI 变得平易近人。你在底部输入，在上方收到回答，复制你需要的内容，然后继续对话。这种交互不应该消失。它快速、熟悉，而且往往恰到好处。

问题始于答案变成工作的时候。

一场营销活动不只是一段文字。它有受众、工作流、落地页、预测、审批，以及负责交付的人。一个模型不只是一个提示词。它有数据集、训练阶段、评估、版本，以及使用它的智能体。产品探索不是一份对话记录。它把客户证据与优先级、视觉概念、任务和已交付的成果连接起来。

Builderforce Creation Canvas 保留了提示词，并改变了围绕它的内容。

## 会话是新的创作容器

Creation Canvas 围绕**会话（Session）**组织，而不是 Project。访客可以在 [builderforce.ai](/) 上输入一个想法，立即进入本地画布，无需账户或分配的团队就能开始创作。完整的草稿保留在这台设备上。访客登录后，Builderforce 会把会话认领到他们的工作区，这样它就可以被保存、分享和交付。

Project 依然重要——但是可选的。当你需要组织上下文、投资组合度量、治理或交付目的地时再添加。一个会话可以不含任何 Project，也可以含一个，或含几个以便比较。

这个区别很重要。创造始于意图。结构应该在有帮助的时候再进入。

## 一切都成为实时对象

在画布上，工作流不是工作流的截图。它是已保存的工作流，带有它的运行控件和规范设置。Website 对象是一个实时的所见即所得原型。Dataset 可以对导入的数据做画像，并为 Chart 或 Dashboard 提供数据。Agent 打开的是与劳动力注册表相同的设置。Evermind 对象可以展开为模型的数据、教学、调优、评估和打包流水线。

其他对象包括 Chat、Project、Task、Roadmap、Slides、Voice、Code、Browser Preview、Staff Member、Report、Note、Drawing，以及可复用的 Frame。

连接是有意义的。一个对象可以向另一个对象提供数据、控制它、把它作为证据引用、展示它，或接收它交付的输出。仅凭空间上的邻近，绝不意味着执行。

![Creation Session 的剖析：有权限管控的 Dataset 和可选的 Project 上下文，为实时的 Workflow、Website 原型、Evermind 和 Agent 对象提供输入；有范围的 Brain 推理产生一个可审阅的变更集，该变更集成为受治理的 Task，并把状态和输出返回给会话](/blog/creation-canvas-session-anatomy.svg)

## Brain 可以跨越整个工作进行推理

底部的输入框有明确的范围：整个画布、当前选区或某个 frame。这使得下面这类问题变得具体：

- “这个营销活动工作流配上这个落地页会有效吗？”
- “比较这两个项目，并创建一份高管路线图。”
- “把这个数据集和草图变成一个交互式仪表盘。”
- “找出需求最多的十个功能，为每个创建一个 mockup，并准备好已批准的那一组用于交付。”

Brain 读取对象及其带类型关系背后的规范上下文。评估结果会留在画布上，带有证据链接、新鲜度、缺口、置信度和拟议的变更。涉及多个对象的变更以可审阅的变更集形式出现，因此由人来选择究竟应用哪些。

## 多人创作包含 AI

已保存的会话支持基于角色的邀请、实时在线状态、光标、选区、评论、@提及和活动时间线。演示模式会移除编辑界面元素。跟随模式让一位协作者可以跟踪另一个人的视口，而不会覆盖任何人自己的视图。

团队可以把 Staff Member 和 Agent 对象拖入一个临时站会 frame。Brain 负责主持进展、阻碍和下一步行动，然后把已批准的后续事项变成 Task 或工作流变更。

在探索时，用户可以创建会话的独立分支。合并时，对每个匹配的对象都会给出明确的选择：使用分支版本，还是保留父级版本。具名检查点和版本历史则提供了另一条恢复路径。

## 创作以交付告终

画布不是一块与执行脱节的灵感板。已批准的 Mockup 可以创建或附加到某个 Project Task，选择一个 Agent，应用该项目的审批策略，并开始一次运行。状态和输出会回到同一个会话中。

这就闭合了聊天工具通常留着不闭合的循环：

**提示词 → 上下文 → 制品 → 评审 → 受治理的执行 → 可度量的成果**

同一个租户会话也可以在 BuilderForce VS Code 扩展中作为原生的完整编辑器标签页使用。Web 协作者可以贡献客户、设计和业务上下文，而开发者则可以把文件或选区、诊断信息、仓库/分支上下文、粘贴的终端输出、本地服务和浏览器预览添加到同一个 Canvas 中。关联的文件直接在编辑器中打开，Session 和对象的评论在各个界面之间保持相连。

聊天仍然是一个很好的起点。Creation Canvas 让你在答案到来之后，依然能守着工作本身。
