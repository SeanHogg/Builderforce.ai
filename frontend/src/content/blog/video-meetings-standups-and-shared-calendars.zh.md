看板告诉你正在发生*什么*。面对面的交流则能迅速告诉你*为什么*。Builderforce.ai 现在把两者放到了同一个地方：实时音视频会议，直接叠在你的团队——人类和智能体——本就在上面工作的那张看板之上。

> Builderforce.ai 通过网状 WebRTC 直接在你的项目看板上举行实时视频会议：站会和回顾会中开启摄像头、临时通话和一对一通话、带每人可用时段的可预约团队日历，以及 Google/Microsoft 日历同步——可以从网页端或 VS Code 内加入，媒体点对点传输，从不经过服务器。

![三个对等端通过 WebRTC 网状网络直接交换音视频；服务器只中继信令并提供 STUN，所以媒体从不经过它](/blog/meetings-webrtc-mesh.svg)

## 会议类型一览

| 类型 | 使用场景 | 谁可以发起 |
| --- | --- | --- |
| **站会 / 规划会 / 回顾会** | 周期性例会，圆桌上开启摄像头 | 管理者开启摄像头；任何成员都可加入 |
| **临时会议** | 一次快速的、临时的同步 | 任何人 |
| **一对一通话** | 一对一的通话 | 任何人 |
| **预约会议** | 提前预约，并以邀请形式同步到日历 | 组织者 |

## 圆桌上的摄像头

Builderforce 本来就把例会——站会、规划会、回顾会——组织成锚定在项目上的结构化圆桌。现在这些例会可以开启**摄像头和麦克风**了。管理者可以为整个团队开启视频，任何人也可以点一下"开启摄像头加入"，把自己加入站会上方的实时画廊。因为会议就挂在例会上，所以大家边聊边看的是同一张看板。

你也可以发起普通通话：发起一场**临时**会议做快速同步，或和某位队友进行**一对一**通话。还有一个专门的 `/meetings` 界面，提供预约弹窗、立即开始，以及进行中/即将开始的会议列表。

## 天生点对点

Builderforce 中的媒体通过**网状 WebRTC 在客户端之间直接交换**。摄像头和麦克风的音视频流、SDP 提议/应答以及 ICE 候选都直接在浏览器之间传输；服务器只中继信令并提供 STUN（配置后也可提供 TURN）。你的视频永远不会落到我们的基础设施上。协商过程无冲突（glare-free），所以两个人在同一瞬间发起连接也不会撞车。

## 一个知道每个人何时有空的日历

会议只有在大家真正都能参加的时间才有意义。Builderforce 在团队成员和项目组合页面上都加入了**共享团队日历**：

- 一个组件同时提供**月视图**和**可预约的周视图网格**。
- 叠加显示你的应用内会议*以及*已连接的 Google/Microsoft 日历事件。
- 用阴影标出你声明的**可用**时段，让空闲时段一目了然。
- 点击一个空闲时段即可预约，点击一场会议即可加入。

只需设置一次**每周工作时间窗口和时区**，**"查找时间"**求解器就会提出*每位*受邀者都有空的时段——没有冲突的会议，且落在每个人自己的工作时间窗口内，时区换算准确无误。再也不用为了约一个时间来回发邮件。

![一个跨时区的周视图网格，显示三个人的工作时间窗口和忙碌时段，求解器高亮出唯一一个所有人都有空的时段](/blog/meetings-find-a-time.svg)

## 接入你自己的日历

每位用户只需一次 OAuth 授权，即可连接 **Google Calendar** 或 **Microsoft Graph**。已预约的 Builderforce 会议会作为真实的日历事件同步出去，并向参会者的邮箱发送邀请；你即将到来的外部日历事件也会直接显示在 `/meetings` 上。一个地方看到所有安排，无需重复录入。

## 随处加入——包括你的编辑器

邀请是需要登录的深层链接（`/meetings?join=<id>`），加入会议**受授权范围约束**：只有组织者、列出的参会者、管理者或该会议所属项目的成员才能加入——跨租户访问会被阻止。而且你不一定非得在浏览器里。VS Code 扩展新增了一棵**会议**侧边栏树，列出即将开始和正在进行的通话：

- **在浏览器中加入**会打开已认证的网页会议。
- **在此加入**会在 VS Code webview 中原生运行 WebRTC 通话——开站会也不用离开编辑器。

## 要点

站会、规划会和回顾会是团队对齐的地方。通过*直接在看板上*以实时视频的形式举行这些会议——再配上一个尊重每个人真实空闲时间的日历，以及 VS Code 里的一个加入按钮——Builderforce 消除了"会议工具"和"工作本身"之间的鸿沟。对话和它所讨论的工单，终于在同一个地方了。

## 常见问题

**Builderforce 使用第三方视频服务吗？** 不使用。音视频通过网状 WebRTC 直接在参与者之间传输。服务器只中继信令并提供 STUN（以及可选的 TURN）；你的媒体是点对点的。

**"查找时间"是怎么工作的？** 每位用户声明自己每周的工作时间窗口和时区。可用时段求解器会提出这样的会议时段：每位受邀者都没有冲突的会议，且时间落在他们的窗口之内，并在不同时区之间正确换算。

**我能同步现有的日历吗？** 可以——每位用户都可以连接 Google Calendar 或 Microsoft Graph。你的外部事件会叠加到团队日历上，已预约的会议也会以邀请形式同步回去。

**谁能通过邀请链接加入会议？** 只有获得授权的人：组织者、列出的参会者、管理者，或该会议所属项目（项目会议）或租户（租户级会议）的成员。链接需要登录，跨租户加入会被阻止。

**不打开浏览器也能加入会议吗？** 可以。VS Code 的会议树让你在浏览器中加入，或在 VS Code webview 中原生运行通话。
