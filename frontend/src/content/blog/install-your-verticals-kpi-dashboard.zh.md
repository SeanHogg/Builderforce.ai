# 一键安装你所在行业真正依赖的指标

问一位 SaaS 创始人她关注什么，她会说净收入留存率、magic number、回本周期。把同样的问题抛给一位生物科技创始人，这些词一个都不成立——他盯的是撑到下一次数据读出的现金跑道，以及支撑他走到那一步的人力成本。

而在此之前，两个人打开的是同一个财务标签页，看到的是同样的三个数字。

这是通用仪表板的无声失败。它并没有错，它只是与**你**无关；而一个与你无关的数字，你终究会停止去看它。标签页加载完成，现金余额准确无误，却没有人学到任何他本来不知道的事。

## 现在仪表板就是模板

KPI 仪表板并不是我们写了十一遍的功能，而是一份**应用市场模板**——和那些安装工作流或 playbook 的模板完全一样：一份小小的清单，声明哪些指标该放在一起，问一句公司规模，然后生成一个可用的看板。

## 空值不是零

耗时最久的细节，恰恰是没有人会提出的那一个：当一块磁贴无内容可显示时，它该怎么做？

把未度量的指标显示为 `0` 的仪表板，是在主动撒谎。净收入留存率为零是一场灾难；*尚无 NRR 数据*只是平平无奇的星期二。在多数仪表板上，这两者看起来一模一样，而代价是：创始人要么为一个并不真实的数字陷入恐慌，要么——更常见地——学会不再信任整个页面。

所以，没有数据支撑的指标只会说明自己未被度量，此外不说任何话。没有占位的零，没有可能被读成数值的短横线，没有凭空捏造的趋势线。你能一眼看出哪些数字是真实的——而这正是依据其中任何一个采取行动的前提。

## 它在方法论中的位置

这是 **Measure**——紧随 Run 之后的一幕。[Read 与 Prove](/blog/read-prove-build-the-inner-loop) 告诉你一件事是否值得做；Build 与 Run 让它上线。Measure 则是你弄清楚它是否真的起了作用的地方，也是最常被跳过的一幕——因为搭一个仪表板，历来本身就是个小项目。

把仪表板变成模板，就把这个小项目压缩成了一次安装。你得到的并不是一个需要配置两周的起点，而是同类公司本就被衡量的那组数字，对接你自己的数据，就在你本来就会打开的那个标签页里。

## 今天你可以用它做什么

- **安装你所在行业的仪表板**：从应用市场进入，或直接从财务标签页的空状态进入——它已经知道你的行业，并直接链接到对应的模板。
- **与现金跑道、现金流并排查看**：仪表板是财务中心的第三个标签页，而不是另一个独立去处。
- **看清哪些数字你还没有在度量**，明确写出来，让「开始度量其中之一」成为一个决定，而不是一次偶然。
- **让区间匹配你的规模**：同一个指标在十人公司和四百人公司有着不同的健康区间，模板会问你一次。
