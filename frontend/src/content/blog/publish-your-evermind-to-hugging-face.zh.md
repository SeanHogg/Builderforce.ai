你教会了 Evermind 你的代码库、你的客服语气、你的行文风格。它通过了就绪检查。它在工作区里作答。然后，工作区之外的某个人要求试用它。

直到今天，老实的答案还是一个 zip 文件。导出面板会构建完整的 Hugging Face 仓库——safetensors 格式的权重、ONNX 图、GGUF 容器、配置、分词器和模型卡片——然后以下载的形式交给你。把它放上 Hub 是你自己的活：解压、安装命令行工具、登录、创建仓库、以正确的方式上传大文件，并祈祷模型卡片在途中没有损坏。这相当于在一个完成的模型和可能使用它的人之间，横着一个小型软件项目。

## 发布，而不是下载

## 你的令牌始终属于你

令牌从页面直接发往 Hugging Face。Builderforce 从不接收它，从不存储它，也从不需要它。仓库属于你的 Hugging Face 账号，而不是我们的，并且你一用完就可以立即撤销该令牌。这也是为什么我们这边无需任何设置：没有需要连接的集成，也没有需要交出的密钥。

## 它在方法论中的位置

这条弧线从 Idea → Make → Run → Measure 一路走来，然后是 **Reach**：让你做出的东西出现在它所服务的人面前。一个只在训练它的工作区里作答的模型，是由构建它的人度量的，而不是由任何可能需要它的人度量的。Reach 是这一点发生改变的阶段，而到目前为止，它是从一项手动打包工作开始的。

## 你今天就能用它做什么

- **公开分享训练好的 Evermind**，放在你自己的 Hugging Face 账号下，连同它的模型卡片，一步完成。
- **从私有开始**，等你准备好时再向全世界开放仓库。
- **发布新版本**到同一个仓库，在你教给模型更多东西之后。再次发布会向仓库添加一个新的提交。
- **保留离线副本**：下载仍然只需点击一下，由同一个包构建。
