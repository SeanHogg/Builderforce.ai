## 个人资料漂移的隐性成本

大多数求职者会在六七个地方维护同一份职业故事——LinkedIn、Indeed、Glassdoor、ZipRecruiter、作品集网站——而且每一处都在慢慢过时。你更新了 LinkedIn，却忘了 Indeed，三个月后，招聘人员打开的是一份标题陈旧、还写着你去年已离开那份工作的资料。

资料漂移会从两方面让你吃亏。对任何交叉核对你各处资料的人来说，你显得粗心；而你最出彩的那个版本只存在于一处，其他平台则在悄悄地低估你。

解决办法是建立唯一的事实来源——一份主简历——再配上一种把它推送到各处的可靠方式。这正是 Profile Sync 所做的事。

## 为每个平台生成可直接粘贴的内容块

[Profile Sync](/tools/vendor-sync) 目前支持九个平台：LinkedIn、Indeed、Glassdoor、ZipRecruiter、Monster、Wellfound、Dice、GitHub，以及任意个人作品集网站。

针对每个平台，它会生成贴合该平台字段的**可直接粘贴的内容块**——Headline（标题）、About / Summary / Highlights（简介 / 摘要 / 亮点，具体字段因平台而异）、经历条目和技能。这一步不需要任何浏览器扩展：打开平台的编辑页面，复制对应的内容块，粘贴，保存即可。内容已经按该平台期望的格式排好，因此不需要再花功夫重新排版。

由于每个内容块都由同一份主简历生成，你的故事在各处都保持一致——只要更新一次主简历，再重新生成即可。

## 借助 Chrome 扩展实现双向同步

安装 Builderforce Chrome 扩展后，Profile Sync 就变成双向的了。

**回拉：** 当你直接在 LinkedIn（或其他受支持的平台）上编辑过资料后，扩展会读取你当前标签页上的资料面板，并提示你把这些修改合并回主简历。你会看到一个合并对话框，可以逐个字段接受或拒绝——在你点头之前，主简历不会有任何改动。

**自动填充：** 在 LinkedIn、Indeed、Glassdoor、ZipRecruiter、Wellfound、Dice 和 Monster 上，你可以一键自动填充 Headline 和 About 字段。你自己打开平台的编辑弹窗，点击自动填充，检查填入的值，然后在平台上点击保存——扩展绝不会自动打开弹窗，也不会自动保存。这和密码管理器的工作边界一致：它负责填写，由你来确认。

## 从设计上保证安全

两道安全护栏确保 Profile Sync 不会给你带来意外。回拉时，合并对话框按字段逐个确认——每一处改动在到达主简历之前都要经过你的批准。推送时，平台始终由你掌控：你打开编辑弹窗，检查填入的值，再点击保存。没有任何事情是在你背后发生的。

隐私的处理方式也是如此。在扩展的设置中打开“不共享匿名使用数据”，即可完全退出遥测。当你选择参与时，扩展只记录事件*类型*（例如“在这个主机上发生了一次捕获，涉及 N 个字段”）——绝不记录字段的具体值或抓取到的页面内容。唯一会离开你设备的数据，是与你的账户绑定的 LLM 提取器调用。

最终的收益是：一份主简历，处处一致，几分钟即可更新，而不必耗上一下午来复制粘贴——你甚至还可以对你在各处发布的版本做 A/B 测试，看看哪个版本带来的回电最多。

## 常见问题

### 使用 Profile Sync 需要安装 Chrome 扩展吗？

只有双向同步才需要。没有扩展，你仍然可以为每个平台获得可直接粘贴的内容块（Headline、About/Summary/Highlights、经历、技能）。有了扩展，你还可以把资料上的修改回拉到主简历中，并在 LinkedIn、Indeed、Glassdoor、ZipRecruiter、Wellfound、Dice 和 Monster 上自动填充 Headline 和 About 字段。

### Profile Sync 会不经询问就覆盖我的 LinkedIn 吗？

不会。回拉时，你会先看到合并对话框，逐个字段接受或拒绝，之后才会改动你的主简历。推送时，你要自己打开平台的编辑弹窗，点击自动填充，检查填入的值，再点击保存——它绝不会自动打开弹窗或自动保存。

### 我可以把不同的简历变体同步到不同的平台吗？

可以。为每个平台选择主简历或任意一个变体即可。Profile Sync 会记住你在哪里发布了哪个变体，这样你就能对比哪个版本带来的回电最多。
