你发给云端模型的每一个 token 都会离开你的电脑，而且每一个都要计费。对大多数工作来说，这是公平的交换。但对于一条私人笔记、一次快速改写、一个关于你不想贴到任何地方的代码的问题，或者在没有信号的火车上度过的一个下午，就不是了。

在本地运行一个小模型一直是显而易见的答案，可它也总是在同一个地方出问题。小模型的上下文窗口很小。先用前沿模型开始一项任务，中途换成本地模型，本地模型收到的对话记录比它能容纳的大好几倍。它会截断、忘掉指令，或者干脆失败。反过来也一样：云端模型接手时，并不知道本地模型刚才做了什么。

这次发布把两头都补上了。现在你可以在自己的电脑上运行模型，就在你已经在用的模型选择器里；当一次运行在模型之间切换时，下一个模型会收到一份按它自己的窗口打包好的对话。

## 选择一个在此设备上运行的模型

在输入框里打开 `/` 菜单，进入 **模型**，选择 **在此设备上**。列表会显示所有能通过 WebGPU 在浏览器 GPU 上运行的模型。点一次 **下载**，浏览器就会保存这个模型，之后它会直接从磁盘加载。

选中这样的模型后，这些回合里的提示词永远不会离开你的电脑。没有发往服务器、可能被记录的请求，没有需要计费的 token；模型下载完成后，甚至完全不需要网络。

## 在模型之间切换，不丢失上下文

真实的工作很少只用一个模型。你在本地模型上私下起草，再把困难的部分交给云端模型。一个模型写计划，另一个模型写代码。某个服务商在运行中途出故障，Builderforce 切换到下一个。过去，每一次这样的切换都会把整段对话发给下一个模型，然后寄希望于它装得下。

现在，每一次切换都会经过 **builderforce-memory**，它会为即将接手的模型打包对话。

规则很简单。系统提示词保留。你的最新指令一字不改地保留。工具调用永远不会和它的结果分开。在下一个模型的窗口允许的范围内，最近的几轮对话原样保留；较早的中间部分合并成一条说明：能生成摘要时就是摘要，否则就是记忆针对你的指令回忆出的内容。打包后的对话总能装进接收它的模型的窗口，并为它的回答留出空间。

## 你可以期待什么

说几个实在的限制，因为一个让人失望的本地模型，比一个从没试过的更糟。

- **需要 WebGPU。** 目前大多数桌面电脑上的最新版 Chrome 和 Edge 都支持。没有 WebGPU 的浏览器或 GPU 无法运行这些模型，选择器会直接告诉你，而不是等到后面才失败。
- **第一次下载比较大。** Bonsai 8B 大约 1.16 GB。它只需下载一次，之后从磁盘加载；你也可以在同一个选择器里移除它。
- **这些是小模型。** 它们擅长起草、改写、回答简短问题和执行明确的工具调用。它们不是前沿模型，面对冗长复杂的任务，云端模型会做得更好。
- **窗口比云端小。** 在支持半精度的 GPU 上，Bonsai 8B 在浏览器里可容纳约 14,000 个 token 的上下文，不支持时约 7,000 个。这正是交接打包存在的原因，也是它在这个方向上最重要的原因。

## 它在方法中的位置

在 Builderforce 上工作遵循一条弧线：**构想 → 制作 → 运营 → 衡量 → 触达**，其中有一个内循环决定什么值得构建：[阅读、证明、构建](/blog/read-prove-build-the-inner-loop)。

- **阅读**变得更便宜、更私密。把一个想法想透、重读自己的笔记、提出那些你绝不会贴进云端工具的问题，都可以在你的设备上完成，不花一分钱。
- **证明**让便宜的部分保持便宜。阅读和证明本就是不该花钱的环节；本地模型让小规模的检查不花一个 token 就能完成，预算留给真正需要前沿模型的那次证明。
- **构建**是交接发挥价值的地方。在本地起草的计划会被打包后交给写代码的模型，指令完整无缺，并附上已经做出的决定。
- **运营**变得更稳定。服务商在运行中途出故障时，接手的模型收到的是一份装得下的对话，所以切换是在继续工作，而不是从头再来。
- **衡量**得到最直接的节省：在你的设备上回答的回合，就是没人计费的回合。

## 你今天就能做的事

- **私下起草。** 在 **在此设备上** 里选择 Bonsai 或 WebLLM 模型，你在这些回合里输入的任何内容都不会离开你的电脑。
- **离线工作。** 出行前先下载一个模型，它完全不需要网络连接。
- **从小处开始，在大处收尾。** 先用本地模型，任务变大时再切换到云端模型。云端模型会收到打包好的对话和一份交接说明。
- **在每个地方用同一个模型。** VS Code、Rovr 和 builderforce.ai 里的选择器都是同一个。
- **看清模型为什么无法运行。** 装不进你设备的模型会告诉你缺了什么，而不是在下载到一半时失败。

打开 `/` 菜单，选择 **模型**，再选 **在此设备上**，下载一个试试。
